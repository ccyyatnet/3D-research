Section 2 · Method

方法详解：O-Voxel → SC-VAE → 生成模型

三级结构：O-Voxel 负责"无损表示"，SC-VAE 负责"紧凑压缩"，三阶段 DiT 负责"高质量生成"。

① O-Voxel：原生 3D 全向体素表示

几何：Flexible Dual Grid（柔性对偶网格）

受 Dual Contouring 启发但完全不使用场表示：直接以网格表面与体素边的交点激活对偶面，每个活动体素存三元组——对偶顶点 v（改进 QEF 闭式求解：平面距离 + 边界边距离 + 正则项）、边交点标志 δ（决定四边形连接）、切分权重 γ（自适应三角化）。

数秒Mesh→O-Voxel（单 CPU）
数十 msO-Voxel→Mesh
任意拓扑开放/非流形/封闭内腔

材质：体积化 PBR 属性（6 通道）

每个活动体素存 f_mat = (c, m, r, α)：基础色（3 通道）+ 金属度 + 粗糙度 + 不透明度 α——α 是首创能力，可处理玻璃等半透明材质。纹理→体素：投影 UV 采样 + mipmap + 距离加权平均；体素→纹理：三线性插值（支持顶点色与贴图两种模式），重建后即可直接渲染。

6 chPBR 通道数
α首创半透明建模
0后处理步骤

② Sparse Compression VAE：16× 紧凑潜空间

纯稀疏卷积网络（~800M 参数：编码器 354M + 解码器 474M），U 形设计，分辨率无关可泛化。三大关键模块：

模块 1

稀疏残差自编码

借鉴 DC-AE：下采样把 8 个子体素特征堆叠到通道维（空间→通道），上采样对称拆回——高压缩比下优化依然稳定（消融：16× 时 MD 退化仅 +69% → 改进后几乎无损）

模块 2

早剪枝上采样器

上采样前预测子体素激活 mask（8 位二值），跳过无效节点，大幅降低显存与耗时

模块 3

优化残差块

ConvNeXt 风格：单层稀疏卷积 + 宽 point-wise MLP（类 FFN）——稀疏数据上比双卷积参数效率更高，零耗时代价提升细节

16×空间下采样率（此前最高 8×）
2.2K512³ 资产 token 数
9.6K1024³ 资产 token 数

两阶段训练：Stage 1 低分辨率（256³）直接特征回归（对偶顶点 MSE + 边标志 BCE + 材质 L1 + 剪枝 BCE + KL）；Stage 2 高分辨率（512³）加渲染感知损失（mask/depth/normal 的 L1+SSIM+LPIPS），随机浅近平面相机"切片"表面以捕捉内外结构。形状/材质解耦：两个 SC-VAE 分别建模，材质 VAE 在形状结构上条件化 → 支持独立的"给定形状生成纹理"。

③ 生成框架：三阶段 Flow-Matching DiT（~4B 参数）

Stage 1

稀疏结构生成

预测稀疏体素占用布局，先训 512² 条件图学习全局占用先验

Stage 2

几何生成

活动体素内生成几何 latent（DINOv3-L 图像条件，cross-attention）

Stage 3

材质生成

生成与几何结构对齐的 PBR 材质 latent（图像 + 几何 latent 通道拼接条件）

每个 DiT 约 1.3B 参数（宽 1536 / 30 层 / 12 头 / MLP 8192），因高压缩而去掉 token packing 与 skip connection，用 vanilla DiT 即可；AdaLN-single + RoPE + QK-Norm 保证稳定性与跨分辨率泛化；rectified flow / CFM 目标，logitNorm(1,1) 时间步采样；渐进式训练 512³→1024³（latent 32³→64³）。

~3s512³ 全纹理生成
~17s1024³ 全纹理生成
~60s1536³（35s 形状 + 25s 纹理）

训练配置

SC-VAE：16×H100，batch 128；生成模型：32×H100，batch 256，AdamW（lr 1e-4，wd 0.01），CFG dropout 0.1。图像条件渲染：每资产 Blender 16 视角，FoV 10°~70° 随机（抗相机内参歧义）+ 光照随机（解耦固有 PBR 与环境光）。

FlexGEMM 自研稀疏卷积后端

Triton 实现的 Masked Implicit GEMM：im2col+GEMM 融合减少显存 IO、Gray code 重排提升 SIMD 效率、Split-K 增加并行度——跨 NVIDIA/AMD 平台，比 Spconv / Torchsparse / fvdb / WarpConvNet 快至 2×。

3.3 形状条件纹理生成 & 3.4 消融

形状条件纹理生成（第三阶段独立使用）

对比 Hunyuan3D-Paint（多视图融合：跨视图不一致 → ghosting/模糊）与 TEXGen（UV 法：chart 歧义 + 接缝伪影）。本文在原生 3D 空间推理外观：纹理更锐利、形状-材质严格对齐，还能为内部表面生成纹理（遮挡/非流形资产的关键能力）。

SC-VAE 消融：去掉残差自编码的代价（MD ↓）

f32（32× 压缩）下退化最剧烈：MD 从 1.405 → 7.394（+526%），PSNR 降 1.6dB —— 稀疏残差自编码是高压缩比的关键。

3.5 推理效率 & 测试时缩放

全纹理资产生成耗时（H100）

1536³ 分辨率 = 形状 ~35s + 纹理 ~25s，显著快于现有大型 3D 生成模型。

测试时缩放（Cascaded Inference）

分辨率外推：1024³ O-Voxel 下采样到 96³ 稀疏结构 → 重跑几何生成 → 得到 1536³ 超训练分辨率结果。质量提升：512³ 下采样 64³ 再生成 1024³ 可修正局部错误、获得更干净的结构布局 —— 以计算换质量的可控权衡。
