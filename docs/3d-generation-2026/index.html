🌍 场景/世界生成的门槛从「看着对」抬到「能跑物理」：Fysiverse 双技术报告要求单图产出的场景在共享重力对齐空间内不互穿、接触可信、可执行 rollout；ESG 把文本编译成 Unreal 可执行的事件驱动场景图；φ-RIE 把选中物体变成可移动仿真资产并补全被遮挡背景；PhysVGGT / SnapPhysics 则直接从单图回归摩擦、硬度、杨氏模量、密度与质量。「可交互、可验证、可执行」已从卖点变成基本门槛。
🗓️ 9 月首个工作周（9/1–9/4，33 篇）：arXiv weekend 不公布，本次实际只覆盖 4 个公布日，产能与 8 月同口径相当。Feed-forward 重建仍占 84/216，但内卷点明显从「新表示」转向「把经典几何重新捡回来」——HiSfM 的层次化 scaffold、BLASt3R / Holistic BA 的 Bundle Adjustment、Scal3R 的位姿图优化，都是在给前馈模型补长期被端到端训练掩盖的全局一致性与漂移问题；Scal3R 只用约 1% 参数、单卡 8 小时就把 KITTI 平均 ATE 砍掉 60% 以上，是一个很强的信号。
🔗 「重建 ↔ 生成」之间的桥梁正在被拆掉：RoGe 直接取消渲染图 / 显式 3D 这条有损中间表示，改为按目标相机射线从隐式场景查询几何特征注入视频扩散并联合训练；InceptionGS 与 DualDiff3D 则走相反方向——用生成先验软性修复欠观测区，再回喂重建。共同点是不再接受「先重建、后生成」的串行链路，与 8 月 GenRec / SceneReGen 的显式划分形成对照。
🌍 世界模型的评测与物理化同时收紧：WorldReward 用 VLM 成对偏好统一「动作一致性 + 视觉质量」并给出 WorldReward-Bench（三维度一致性超 GPT-5.5 3.42 / 1.45 / 3.56 pp），TourPhysics 让确定性仿真先算轨迹再交给生成器、OctWorld 用八叉树 TSDF 做持久化 3D 记忆，Streaming4D 把视频块生成与增量重建同步化——「可交互、可验证、长程不漂」已从卖点变成基本门槛。
🧵 资产可编辑性继续向生产管线深处走：SeamFlow 用 flow matching 做类美术 UV 展开、GradRig 用蒙皮权重梯度解决 3DGS 拉伸孔洞、GS Palette Editing 把调色板编辑搬到视图空间以消除 alpha 混合外溢、Line Primitives IR 用显式线段重建毛发纤维以接回标准光栅化管线。这批工作共同指向本站反复遇到的那个缺口：能生成 ≠ 能进引擎。
🚀 Feed-forward 3DGS 仍是绝对主力（70/183 篇，38%）：下半月内卷点从「能不能重建」转向表示质量——LocusGS 给查询加 3D 锚点、SeeU 补欠观测区域、GroupForward 做实例分组、Per-View Predictions 去干扰物，都是在修 pixel-aligned 表示的结构性缺陷；6–7 月的同类工作还有 RefineSplat（熵掩码去干扰物）、Scenes as Objects（无位姿实例级 3D token）、DPPE（解耦相机位姿编码）、WarpHammer（用 3D 生成先验补极端视角）；6–7 月前馈侧的主线则是把输入条件放宽——Wild3R / WildSplat 吃野外光照变化与瞬态物体、FreeStreamGS 吃无位姿流式输入、PRISM 单图 36 秒、LIST3R 处理长序列、OmniX 做到任意视角任意时刻；8 月则集中在几何可信度与输入鲁棒性——TopoSurfel / CoMVS-GS 攻表面重建，GeoWeaver 与长时序局部上下文（缓存前 11 帧 KV，误差降约 40%）攻长序列漂移，WilLaGS 用隐条件外观场吃野外光照，偏振不透明度先验与 FRA-NBV 分别用偏振与反射线索补退化表面；视频先验也被直接拿来补 3D——4DAnyone 从随手单目视频建 4D 人体、Stream4D 用前馈 4D 重建奖励给流式自回归视频模型加 4D 一致性、FixAnything 用一个视频生成模型统一修复 3DGS / NeRF 等四类表示的渲染伪影。
🧩 「重建 vs 生成」的边界正在被显式建模：GenRec 在架构里内置何处重建/何处生成的划分，SceneReGen 把场景重建重释为「生成+装配物体资产」，GaussVid / FixAnything 引入视频扩散先验补未观测区。生成式补全正成为重建的默认第二引擎。
🎨 资产管理级需求浮出水面：Luce（PBR 可重光照）、Gen2Physics（材质分解→物理属性）、Cyc3D（资产可用性评测）三条线同时出现，说明业界关注点已从「渲出来好看」转向「能进引擎、进仿真、进产线」；6–7 月这条线继续加密：MaterialClusterGS（调色板 BRDF + 2DGS 重光照）、AEGIR（显式建模面光源的逆渲染）、3DGS 本征分解与编辑、可编辑光线追踪反射、GRay（光追做到 splatting 速度）。
🤖 Agent 化与可编程化：DesignAgent3D 用「规划-感知-行动」做交互场景编辑，NeoWorld-Pro 让 MLLM 把单图编程成可执行仿真程序并由物理引擎闭环校验；世界生成从「端到端输出」走向「可干预、可验证」。
⚡ 效率成为 T2-3D 的硬指标：Block3D 用分块扩散把端到端时间砍到 1/5，SemanticSlider3D 走免训练编辑路线——生成质量之外，推理成本与可编辑性正被放进同一张评分表。
🗂️ 部件级可控生成显著升温（32 篇）：MegaParts 撑到 300 部件、MultiCube 控部件语义与空间、SCULPT 用减材组合，与 Buffalo / PartMat 的部件生成主线形成合力；ISAP-3D 用身份槽对齐解决部件的身份-布局纠缠；8 月另有一条线是把 3DGS 变成可编辑、可评估的资产——Seed2GS（无相机无训练的目标提取）、PartInteractor（部件感知的 XR 协同创作）、Super-Gaussian（自然语言交互的体数据编辑）、3DGSI-Assessor（15.2K 图像的 3DGS 渲染质量数据集 + LVLM 评估）。
📐 结构化 / 参数化生成抬头（6–7 月主线）：Arko-T 直接生成可编辑的参数化 CAD 程序、Arbor 用约束网格做原生 3D 控制接口、TopoGS 把高斯基元锚定到结构元素 —— 目标从「生成像什么的形状」转向「生成能改、能装配、能进 CAD 的东西」；P3D-Bench 则首次系统评测 MLLM 写参数化 3D 程序的能力（文生 3D / 图生 3D / 装配 3D 三类任务）。
⚠️ 评测协议本身开始被质疑：AMD 的 Mind the Gap 指出标准 3DGS 的隔帧留出只衡量近轨迹插值，插值与外推差 3–12 dB 且跨表示族存在；SpatialQ 用 VGGT + MLLM 做结构感知质量评估，Cyc3D 用视角循环协议评资产可用性。「怎么评」正成为独立研究方向。 6–7 月又增两例：3D-DefectBench 用平衡因子实验量化 VLM 评测管线各环节的影响（模型选择影响最大、因素间存在交互），Judging to Improve 给出去偏的 VLM-as-3D-Judge 协议并把「评判」从排序扩展到优化。
🖼️ 新视角合成是 6–7 月最卷的赛道（本轮新增 14 篇落在 FF 重建）：主线已从「多给几张输入视图」转向更难的成像条件与更强的控制——DeblurNVS 处理运动模糊、PanoImager 免 SfM 做稀疏全景、WarpHammer 攻极端大轨道视角、NeoMap 走免训练路线、SPoILeR 用纯 RGB 监督外推到光谱/偏振多模态；同时 CanonicalGS（稳定规范空间）与 DPPE（解耦位姿编码）在补前馈表示与相机条件化本身的稳定性短板。
🌐 世界模型从「生成视频」走向「可交互 + 物理一致 + 长程记忆」：CP4D 用「静态环境 + 物理动态对象」组合式建模并接物理模拟器出轨迹，P3Sim 引入持久场景记忆在部分观测下推演未来状态，Ground4D / Hallo4D 分别解决单目视频 4D 重建与 3D/4D 生成的时空幻觉；交互式视频世界建模综述则把动作可控性、长程记忆与实时响应列为三大公开瓶颈；SimuScene（物理引擎诊断并驱动重建修正）、OVOW（单目视频 → 实例级可仿真 4D 网格）、场景级异构物理仿真则构成「为仿真而生」的三条路线。
⚙️ 物理一致性在 8 月独立成赛道（单月 6 篇）：LaGSplat（潜拉格朗日 GS，从单目视频推断物理控制的交互式模拟）、4DGS-WAM（以对象为中心的 4DGS 世界动作模型，桥接过去重建与未来预测）、LagrangeGS（把动态 3DGS 建成非保守拉格朗日系统，可稳定外推且时间可逆）、隐式本构定律（从单目视频学材料本构）、ChainSplat（螺旋理论学习可变形线性物体动力学）、物理集成算子学习（FFGS 表示做 PDE 长时序预测，相对 ℓ₂ 误差降 1.5–2.2×）。共同点是把 3DGS 从「渲染表示」升级为「可仿真介质」。
🔬 渲染与硬件基建同步推进：VoroTracing（可微 Voronoi 光线追踪，RTX 5090 上 623 FPS）、3DGART（粒子反向传播让全光追高斯训练实用化）、RoofGS（Roofline 指导，4K 场景 10.1× 加速）、ABCD（块坐标下降把峰值显存降到 O(1)，小显存 GPU 也能训大辐射场）、ESVR（椭球基元稀疏体绘制）。另有 Transparency Rendering in CAD 综述系统梳理 CAD 透明渲染的近似/精确权衡、强调内部组件的技术与 CSG 挑战，与本站透明材质调研直接相邻。
🧱 表示层出现「反潜变量」回摆：PixWorld 直接在像素空间统一场景生成与重建（不需要预训练自编码器）、3D-CoS 把 3D 资产表示为可执行的 Blender 代码、超二次曲面扩散把生成目标换成紧凑参数化基元、FLAT 从视频扩散潜变量直接解码三角形泼溅、SeamGen 生成贴艺术家习惯的 UV 布局。共同诉求是「生成的东西要能被程序读、被人工改、被约束驱动」，而不只是看着对；8 月这条线继续——球形占用轮廓把逐光线占用作为重建与生成共享的统一中间表示、Gaussian-JEPA 给 3DGS 补上自监督的联合嵌入预测目标、PixSDS 则从理论上解释潜空间 SDS 为何产生带噪像素并给出 VAE 一致性梯度修复。
