趋势观察

🚀 Feed-forward 3DGS 仍是绝对主力（35/86 篇，41%）：下半月内卷点从「能不能重建」转向表示质量——LocusGS 给查询加 3D 锚点、SeeU 补欠观测区域、GroupForward 做实例分组、Per-View Predictions 去干扰物，都是在修 pixel-aligned 表示的结构性缺陷。
🧩 「重建 vs 生成」的边界正在被显式建模：GenRec 在架构里内置何处重建/何处生成的划分，SceneReGen 把场景重建重释为「生成+装配物体资产」，GaussVid / FixAnything 引入视频扩散先验补未观测区。生成式补全正成为重建的默认第二引擎。
🎨 资产管理级需求浮出水面：Luce（PBR 可重光照）、Gen2Physics（材质分解→物理属性）、Cyc3D（资产可用性评测）三条线同时出现，说明业界关注点已从「渲出来好看」转向「能进引擎、进仿真、进产线」。
🤖 Agent 化与可编程化：DesignAgent3D 用「规划-感知-行动」做交互场景编辑，NeoWorld-Pro 让 MLLM 把单图编程成可执行仿真程序并由物理引擎闭环校验；世界生成从「端到端输出」走向「可干预、可验证」。
⚡ 效率成为 T2-3D 的硬指标：Block3D 用分块扩散把端到端时间砍到 1/5，SemanticSlider3D 走免训练编辑路线——生成质量之外，推理成本与可编辑性正被放进同一张评分表。
🗂️ 部件级可控生成显著升温（10 篇）：MegaParts 撑到 300 部件、MultiCube 控部件语义与空间、SCULPT 用减材组合，与 Buffalo / PartMat 的部件生成主线形成合力；ISAP-3D 用身份槽对齐解决部件的身份-布局纠缠。
📐 结构化 / 参数化生成抬头（6–7 月主线）：Arko-T 直接生成可编辑的参数化 CAD 程序、Arbor 用约束网格做原生 3D 控制接口、TopoGS 把高斯基元锚定到结构元素 —— 目标从「生成像什么的形状」转向「生成能改、能装配、能进 CAD 的东西」。
⚠️ 评测协议本身开始被质疑：AMD 的 Mind the Gap 指出标准 3DGS 的隔帧留出只衡量近轨迹插值，插值与外推差 3–12 dB 且跨表示族存在；SpatialQ 用 VGGT + MLLM 做结构感知质量评估，Cyc3D 用视角循环协议评资产可用性。「怎么评」正成为独立研究方向。
