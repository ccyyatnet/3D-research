趋势观察

🚀 Feed-forward 3DGS 重建是绝对主力（12/28 篇）：各团队在流式推理（StreamSplat）、无位姿输入（NoDrift3R）、恶劣条件（DerainSplat）、免标定（FlexSplat）、表示解耦（QuerySplat）上持续内卷。
🎨 文/图生 3D 转向可控性与垂直场景：风格化（DreamStyle3D）、服装（Fashion-3DLR）、汽车（3DCarGen）、动态人体（4DHumanDiff），从"生成万物"走向"按需生成"。
🌍 3D 世界引擎/基础模型兴起：EmbodiedGen V2、Glob3R 对标 2D 基础模型路线；Agentic 世界生成成为新热点（WorldClaw 全代理编排、HoloWorld 室内外统一城市），从"生成资产"走向"生成世界"。
🧠 VLM 深度赋能 3D 生成：VLRC 用 VLM 信号预训练、图验证 VLM 场景生成、Buffalo 统一理解-生成-编辑，"理解驱动生成"成为新范式。
