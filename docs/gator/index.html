先生成一个完整资产，再让 Agent 当修理工
GATOR：随手拍图像的生成式 + Agentic 3D 物体重建

从随手拍（casual images）恢复完整、场景对齐的物体，难在两件事要同时做对：把没看见的部分补全，以及把看见的部分忠实还原——尤其纹理。 纯生成式（TRELLIS.2、Pixal3D）补得出来但细节糊、文字乱码、背景污染；纯 Agentic（GPT-6-Astra 从零用 Blender 建模）能显式控制但慢且会把零件简化成方块。 GATOR 的解法是让两者各干各擅长的一半：用 TRELLIS.2 的三阶段级联先出一个完整、带 PBR、带场景相对位姿的资产（约 32 秒）， 再把这个资产连同输入照片和 Blender 一起交给多模态 Agent做局部修补——补全缺失部件、修复拓扑、修纹理。 本页除常规解读外，重点拆开第 ⑤ 节的纹理修复机制：论文附录 Prompt 1 里那段「Texture and material repairs」是我见过写得最细的 agentic 纹理修复约束，逐条都有明确的反偷懒意图。

SECTION 01 · TAKEAWAYS

先把结论读完

七条，其中第 4–7 条是本站读完全文（含附录与两份 agent prompt 原文）后的判断，不是论文原话。

结论 01 · 定位

「生成做 builder、Agent 做 refiner」比反过来便宜 40 倍

GATOR 不加 agent 的纯生成约 0.5 分钟，质量已超过跑 20 分钟预算的 GPT-6-Astra 从零建模。而 GPT-6-Astra 在 1 分钟预算下 10 个物体一个都交不出有效资产（0/10），2 分钟 5/10，5 分钟起才 10/10。这是本文对 agentic 3D 路线最有价值的结论：Agent 应该修，不该造。

结论 02 · 架构

三个贡献点里，最易被忽略的是「同一份 mask 的两种相反用法」

结构流看完整 crop（含遮挡物和桌面），mask 作为独立 token 送进去——为了在补全被遮挡部分时知道周围有什么；几何/外观流只看去背后的图——为了不让背景和邻近物体泄漏进纹理。论文点名 TRELLIS.2 / Pixal3D / ReconViaGen 是「每阶段都去背」，把场景上下文丢掉了。

结论 03 · 纹理

纹理修复的本质是一个「信息在哪」的二分类决策

Prompt 1 的骨架是：若图集（atlas）里已经有那个细节 → 修 UV 映射；否则 → 用干净的局部 RGB 对应从照片补。先查信息是不是已经在纹理图里（只是映射错了），不在才做投影。这个决策顺序避免了「动不动就重投影一遍」的常见退化。

结论 04 · 纹理（本站）

那段 prompt 里的禁止条款，全是在堵 agent 的低成本伪造路径

「改一个材质标量不算恢复细节」「不许编造读不出的文字或品牌」「不许用纯色涂抹替换有辨识度的表面」「不许克隆重复痕迹」「不许用 alpha 贴图假装镂空」。 五条禁令指向同一件事：agentic 修复的默认失败模式就是用一个便宜操作让渲染图看起来变好了。写这类 prompt 时这五条值得直接抄。

结论 05 · 评测（本站）

agent 的收益集中在感知指标，SSIM 反而会降——这是诚实的信号

三个真实数据集上 PSNR 与 LPIPS 全线改善，但 SSIM 在 HANDAL 上从 0.927 降到 0.917、消融里从 0.925 降到 0.918。原因是局部重投影/重绘改变了像素级结构统计。如果你的下游看 SSIM，agentic 精修未必划算。

结论 06 · 评测（本站）

几何指标变差 ≠ 结果变差：CD/F1 对「能不能站住」完全不敏感

HANDAL 上加了 agent 后 CD 0.008→0.009、F1 0.936→0.923、IoU 0.757→0.728，全都略降。但放到 PyBullet 里，同样这批椅子从倾倒 40–79°变成1.3° 内稳稳立住。这是全文最有说服力的论证，也暴露了当前 3D 重建评测的盲区。

结论 07 · 口径提醒（本站）

这篇的 PSNR/SSIM/LPIPS 不评估「材质恢复得对不对」

附录 C.3 明确写了：参考 CAD 模型的颜色来自真实拍摄，渲染时统一用粗糙漫反射材质，分数衡量的是「与渲染参考的一致性」而非「标定的材质恢复」。做 PBR 的同学要注意这个口径——PBR 通道（roughness/metalness）的正确性在本文实验里没有被直接评测。

结论 08 · 局限

agent 编辑的正确性目前靠 LLM 自己看图判断

edit-render-review 闭环是「渲染原版和候选版、让同一个模型比对、退化了就 revert」——校验者就是编辑者。论文自己在 D.7 把「agent 编辑的自动几何校验」列为未来工作。加上闭源 GPT-6-Astra + 每物体 10 分钟，工程落地成本不低。

SECTION 02 · PROBLEM

「随手拍」到底难在哪

不是简单的「单图/多图重建」，而是四重不确定性叠加，且每一重都会直接反映到纹理上。

难点 1 覆盖不全

物体可能只被看到一两面，背面完全没观测。没看见的部分只能靠先验生成——生成得「看起来合理」和「实际长那样」是两回事。

难点 2 遮挡与杂乱

目标混在桌面/房间里，被别的物体压着挡着。纹理层面直接表现为背景污染：邻近物体的颜色被投影到目标表面上。

难点 3 相机与深度是估的

不要求标定。用 Pi3X / VGGT-Ω 估相机与深度，本身就是噪声。投影错一点，纹理就糊一格、文字就乱码。

难点 4 还要位姿

不只出资产，还要能放回原场景。所以输出必须是场景相对位姿，而不是规范坐标系里的孤立物体。

输入 / 输出的形式化

C = ( { Iv, Mv, Kv, Tv, Dv }Nv=1, c ) 　←　RGB、目标掩码、内参、位姿、深度（全部可以估出来）+ 文本 c（类别名或 VLM caption）
q = (x − tg) / sg 　,　 x = sg q + tg 　←　归一化只做平移和缩放，绝不旋转，所以输出天然保持场景相对朝向（附录 A.1）
为什么「不旋转」这件事很关键。 多数生成式重建把物体规范到自己的 canonical frame，出来之后还得再估一次位姿才能放回场景。GATOR 用 masked depth 反投影的中心 tg 与等方尺度 sg 做归一化，坐标系轴向与输入一致——生成出来的资产自带正确朝向，之后只用一个可微渲染的 placement 步骤微调平移与尺度（朝向和局部几何锁死不变）。这是它能直接做 ADD-SB（joint pose+shape）评测的前提。

对比：两条路各自的短板

单图/多图生成式
LRM · TRELLIS.2 · SAM 3D
背面靠先验推断，视觉上合理 ≠ 实际正确；多视图要靠额外适配。
多视图生成式
ShapeR · ReconViaGen · Pixal3D
多模态常作为独立条件流喂进去，去噪器得自己推断局部对应关系；Pixal3D 还隐含假设锚点视图里目标全可见，遇遮挡就脆。
纯 Agentic

从零写代码建模：反复调用 + 渲染，慢且贵；细粒度几何仍难，会把零件简化成方块（论文 Fig. 1 的滤锅耳朵与把手）。

SECTION 03 · METHOD A

Local Modality Mixing：先把「同一个 patch 的三种证据」绑在一起

核心设计是把 patch 级的跨模态融合，和全局的跨视图推理，拆成两件事先后做，而不是一股脑丢进 denoiser 让它自己学。

图 1：GATOR 三阶段级联（对应论文 Fig. 2A）。注意掩码在两个阶段的用法相反，这是防纹理污染的第一道闸。

Modality Mixer 的形式（式 1）

{ ĥmvp }m∈{I,M,P} = ModalityMixer( { hmvp + avp }m∈{I,M,P} )　，　avp = A( γ(up), rvp ) 　←　对同一个 patch 的 RGB / mask / pointmap 三个 token 做残差注意力；输出 token 仍保留各自模态身份

为什么是 patch 内而非全局设计

把已知的空间对应写进架构，而不是留给去噪器去学

三种模态本来就共享同一个 patch grid 和同一套 2D 位置 + Plücker 射线编码，对应关系是已知的。ShapeR 是各自编码后在 denoiser 里合并，RecGen 干脆把 mask 和 pointmap 的 embedding 直接加到 image token 上——后者连「哪块是目标」都糊进了外观特征里。

副产品：天然抗上游估计误差收益

三个线索互相交叉验证

同一 patch 的三种证据同时可见，模型可以拿外观和 mask 去交叉核对深度。消融里加 mixer 后 ADD-SB 从 0.057 降到 0.037（越小越好）——因为相机和深度都是估的，这个改进基本就是抗噪能力换来的。

结构流用全局注意力分工

稀疏结构还不知道，没法做局部投影

dense structure latents 对所有视图的混合 token bank 做 cross-attention。对比 Pixal3D 从锚点视图做局部投影——它隐含假设目标在锚点视图里全可见，遇到遮挡就脆。GATOR 这个选择在「覆盖不全 + 遮挡」场景下明显更稳。

文本语义条件：三个阶段各用各的

  • 结构流：SigLIP2 池化的短类别名（如 "a mug"），经 adapter 后调制 timestep embedding 与 adaLN——是全局调制，不是 token。
  • 几何流 / 外观流：冻结的 T5Gemma2 + 可训练 adapter 产出文本 token，走交叉注意力；训练时 caption 从「简短类别名」到「详细长描述」都有，目的是给更细的引导。
  • 对比 ShapeR：只在 shape denoiser 里加文本 token，几何外观阶段完全没有。
消融里的文本贡献（Table 4，55 个 HANDAL 物体）。加文本后九个指标全部改善：ADD-SB 0.037→0.032、CD 0.011→0.008、F1 0.872→0.930、PSNR 18.16→18.93、LPIPS 0.114→0.102。这是消融四行里改善最整齐的一行——说明类别语义在观测稀疏/被遮挡时确实能替外观补位，而且连纹理指标都吃到了红利（PSNR +0.77 dB）。
SECTION 04 · METHOD B

同一份 mask 的两种相反用法：这是纹理防污染的第一道闸

论文 §3.4 专门有一小节叫「Masks across stages」。这段很短但信息密度极高，而且是理解后面纹理修复的前提。

阶段看到的图像mask 的角色为什么这么设计纹理层面的后果
① 结构流 完整 crop（含遮挡物、支撑桌面） 作为独立 token与 RGB/pointmap 并列 补全被遮挡部分时，需要知道「周围有什么挡着、物体搁在什么上面」 间接影响：结构边界错了，后面投影的纹理位置就错
②③ 几何/外观流 target-masked 图像（去背） 直接把图裁掉 表面细节和纹理只需要目标自身的信息 直接决定：邻近物体与背景不会泄漏进纹理
TRELLIS.2 / Pixal3D / ReconViaGen 每个阶段都去背 — — 结构阶段也丢掉了上下文，补全被遮挡物体更困难
这段设计的现实动机。 论文 §3.5 第一句就点明了生成阶段之后残留的三类缺陷："missing parts, fused openings, or texture contamination"（缺失部件、开口被糊死、纹理污染）。 也就是说——即便做到了「外观流只用去背图」，纹理污染依然存在，只是从「背景污染」降级成了更细的问题：UV 映射错误、文字乱码、烘焙光照残留、邻近物体局部渗色。这正是第 ⑤ 节 agent 要接手的部分。

外观流的投影条件（式 2、式 6）

fj = 1/|Vj| · Σv∈Vj [ FDv(πv(sgqj + tg)) ; FNv(πv(sgqj + tg)) ]　← 式 2
Δh(ℓ)j = CrossAttnℓ( LNℓ(h(ℓ)j), G ) + Wℓ fj + bℓ　← 式 6：全局 token 走交叉注意力，局部特征走加法
  • 双编码器取特征：冻结 DINOv3 特征 + 其 NAF 上采样版本（Chambon et al., CVPR 2026），拼在一起。NAF 补的是 DINOv3 下采样丢掉的高频细节——对文字、logo、颜色边界这类东西很关键。
  • 多视图平均：只对「坐标在相机前方且投影落在 crop 内」的视图求平均；一个都没有就置零。
  • 不做遮挡测试（与 Pixal3D 相同）：沿相机射线的所有坐标都拿到它投影到的像素特征，靠 masking 把遮挡物挡在特征之外。
  • G 是什么：5 个视图平均后的 DINOv3 class + register token，加 T5Gemma2 文本 token。
  • 训练/推理不对称：两个 flow 都在 GT 稀疏结构上训练，推理时用预测的稀疏结构——这个 gap 是误差来源之一。
  • 对齐补救（附录 A.3）：观测很少时，先把生成结构与观测对齐再重算归一化，消除投影前的坐标错配；训练时特意用 perturbed / estimated cameras，让 flow 容忍残余错配。
SECTION 05 · TEXTURE REPAIR ★ 重点

Agentic 纹理修复：把「Texture and material repairs」这段 prompt 逐条拆开

论文附录 A.4 给了两份完整 prompt。下面这段是 Prompt 1（精修模式）里的纹理与材质专节——原文 13 行，我按语义切成 9 条，每条标明它在防什么。

5.1 闭环：edit → render → review → keep or revert

图 2：edit-render-review 闭环 + 纹理决策树。校验者与编辑者是同一个模型——这是它最大的软肋（见结论 08）。

5.2 逐条拆解：这 9 条在防什么

#Prompt 原文要点（英）中文拆解它在防什么 / 本站备注
1 Diagnose geometry, UV, base color, normal, roughness/metalness and baked-lighting errors separately. 六类错误分开诊断：几何、UV、基色、法线、粗糙度/金属度、烘焙光照。 防「一上来就调材质」。这六类的修法完全不同，混着改等于把病因搞混。
2 A material scalar change does not restore recoverable detail. 改一个材质标量，不算恢复了可恢复的细节。 反偷懒 最直白的一条。把 roughness 从 0.5 调到 0.3 会让渲染图「看起来不一样」，但没有恢复任何真实信息。
3 If the atlas contains the detail, repair UV mapping. Otherwise use clean local RGB correspondence to restore visible labels, color boundaries and patterns. 图集里已有细节 → 修 UV 映射；否则 → 用干净的局部 RGB 对应恢复可见的标签、颜色边界、图案。 核心决策树 先判断「信息在不在纹理图里」：在就是映射错了，重映射即可（无损、不引入新噪声）；不在才动用照片投影（有损、受位姿误差影响）。
4 Check orientation and stretching. 检查纹理朝向与拉伸。 UV 重映射后的两个典型次生缺陷。拉伸在整物体视角下很容易被忽略，所以 prompt 还要求「若小修复在整体尺度下看不出，要额外提供一个紧凑的局部对比 rig」。
5 Do not invent unreadable text or brands. 不要编造读不出来的文字或品牌。 反幻觉 宁可保留模糊，也不伪造「看起来像字」的东西。做仿真/电商资产时伪造品牌是法律风险，这条同时是合规条款。
6 Remove neighbor/background contamination locally, avoiding cloned repeated marks or uniform paint replacing a distinctive surface. 局部移除邻近/背景污染；禁止克隆重复痕迹；禁止用纯色涂抹替换有辨识度的表面。 反偷懒 两条具体禁令都很准：克隆印章（clone stamp）会产生周期性重复纹理，纯色覆盖是最省事的「假修复」。两者都让指标变好但丢了真实外观。
7 Preserve appropriate PBR maps; give new parts connected compatible materials rather than white defaults. 保留合适的 PBR 贴图；新补的部件要给与相邻部件兼容的材质，而不是白色默认值。 直接对应下游可用性：默认白模在仿真和游戏里就是废资产。这条把「补几何」和「补材质」绑成了一件事。
8 Use supplied estimated cameras/depth as noisy evidence, not exact geometry. 估计的相机/深度是噪声证据，不是精确几何；注意相机约定，必要时用局部锚点。 防止 agent 过度信任投影结果。与正文 §3.4「训练时用 perturbed/estimated cameras」是同一个思路，只是在推理阶段用 prompt 再兜一次。
9 Retain an earlier good repair if a later texture projection regresses. 如果后一次纹理投影导致退化，保留前一次那个好的修复。 回归保护 与全局的 checkpoint/revert 机制呼应。说明作者清楚：纹理投影是会退化的操作，不能假设「多修一次就更好」。

5.3 另外三条散落在别处、但同样管纹理的约束

用 review --clay 验证真开口防纹理伪装几何

"Strainers, whisks and baskets require actual wire gaps/perforations, not alpha paint on a solid shell."

不许在实心壳上用 alpha 贴图假装镂空。滤锅、打蛋器、篮子必须有真实的金属丝间隙/穿孔。验证手段是 review --clay——用完全不透明材质渲染，这样 alpha 伪装无处遁形。

这条很值得抄：用「关闭某个通道」的方式去验证「这个效果是不是靠该通道伪造的」。

换掉局部损坏面后要恢复 UV/材质几何→纹理联动

"Remove competing damaged faces, attach cleanly, and restore UVs/materials."

当贴补救不回来时，允许整块换掉损坏的局部表面/部件；但换完必须干净地接上，并恢复 UV 与材质。避免浮空碎片、重叠盖片、把功能性孔洞糊死、或为了藏损伤把整个部件压平。

不许用 trivial shader 改动冒充完成验收

"Do not stop at a trivial shader change while a required structural repair is feasible."

在结构性修复仍可行时，不许停在「改了下 shader」就收工。反过来也写了：「若原版已经合适，检查后原样交付；绝不伪造改进，也绝不把失败的修复悄悄标成完成。」（桌腿缺失的例子：只做纹理清理是不够的。）

修不动时要标 needs_review 并写明真实残留缺陷——「一个诚实的 needs_review 优于耗尽时钟写文档」。

Prompt 2（从零重建基线）里的对应条款，可以看成对照实验。 同一个 agent 在没有初始网格时，纹理要求降级为："Reconstruct distinctive colors, texture placement and material response. Use photograph-derived texture with defensible correspondence... Plain PBR is appropriate for unobserved surfaces, not a substitute for visible instance-specific detail." ——即「看不到的面用纯 PBR 就行，但不能拿它替代可见的实例专属细节」。有了 GATOR 的初始资产之后，纹理要求从「大致对」升级到了「可读、不污染、不伪造」。这就是「先生成再精修」在纹理维度的具体红利。

SECTION 09 · LIMITATIONS

局限与本站判断

前四条是论文 D.7 原文，后四条是本站读完全文后的补充。

1 依赖 mask 与相机/深度估计

混合模态降低了敏感度（消融里 ADD-SB 0.057 → 0.037 就是证据），但灾难性失败仍会毁掉重建：分割丢了、深度完全错。没有兜底机制。

论文 D.7 原文。

2 Agent 是闭源 API + 每物体 10 分钟

成本与可复现性都是问题。本文所有 agent 实验都建立在 GPT-6-Astra 上，换模型结论是否成立未知。

论文 D.7 原文。

3 编辑正确性的校验者 = 编辑者

edit-render-review 让同一个模型判断自己的修改是否退化。没有几何层面的自动校验——论文把它列为未来工作。这意味着失败模式是系统性的：模型看不出的错误会一路留到交付。

本站：这是 agentic 3D 编辑路线的通病，本文提供了闭环与 revert，但没解决校验独立性问题。

4 外观评测不评估材质正确性

附录 C.3 明确：参考 CAD 用粗糙漫反射材质渲染，分数衡量与渲染参考的一致性，不是标定的材质恢复。所以 PBR 通道（roughness / metalness / normal）的正确性本文没有直接验证，尽管模型输出的是 PBR latents。

本站：做 PBR 的人要注意这个口径，别把 PSNR 当成材质恢复质量的证据。

5 消融模型与主模型不可直接比

论文 D.5 明确说：Table 4 的消融模型是单独训练的，分数与 Table 2 / Table 6 不可直接比较。引用消融数字时要带上这个前提。

本站：这点论文自己标注了，值得表扬，但也意味着消融的绝对值不能当主结果用。

6 训练/推理的结构 gap

几何流与外观流在 GT 稀疏结构上训练，推理时用预测结构。这个 gap 在观测稀疏时会被放大。附录 A.3 的「先对齐再重算归一化」是补救，但不是根治。

本站：与 Flow3D-Pro 那类两阶段系统面临的是同一类问题。

7 ScanNet++ 用部分扫描做 GT

ScanNet++ 只提供部分扫描的参考网格，对齐只拟合到观测表面，但对称距离仍会惩罚扫描没覆盖到的补全表面。补全得越好，可能罚得越多。

论文 D.4 说明了这一点；本站认为这会让该 benchmark 上的 CD 系统性低估方法真实水平。

8 纹理修复的可验证性仍是空的

「不许编造读不出的文字」写了，但没有机制去验证 agent 是否真的遵守了——校验的还是那个模型自己。要真正落地，需要的是 OCR 一致性检查、跨视图纹理重投影误差这类确定性判据。

本站：这是把这套 prompt 用到生产里之前必须先补的一环。

一句话总结。 GATOR 最有价值的贡献不是某个新模块，而是把「生成式重建」和「agentic 编辑」的成本结构摆正了：生成负责 0.5 分钟内出完整、带位姿的资产，agent 在这上面做 10 分钟的局部纹理与结构修补。 对做纹理的人来说，附录 Prompt 1 那段「Texture and material repairs」是全文信息密度最高的部分——它本质上是一份「agentic 纹理修复的失败模式清单」，五条禁令分别对应五种低成本伪造。 而它给出的量化证据也很诚实：PSNR + LPIPS 全改善，SSIM 会降，几何指标可能变差——但椅子能站住了。
