别再让 3D 生成器去猜材质
SUPRA-Tex：把已对齐的 PBR 观测钉在表面上，再谈补全

单图 3D 生成要给网格穿上可重光照材质，同时忠实保留参考图细节。两条主流路线各有硬伤： 多视图合成再融合 → 跨视图不一致导致接缝与鬼影，融合冲突预测会模糊锐利的参考细节； 原生 3D 生成（TRELLIS.2 一类）→ 图像 cross-attention 不提供细节与表面位置的显式对应，模型得自己学"细节该放哪"。 即便像 Pixal3D 那样把图像特征按相机投影搬到 3D，这些条件仍然是视觉特征而不是材质观测——3D 生成器要同时承担「从视觉特征推断 PBR」「在对应位置重建细节」「合成未见区域」三件异构的事。 本文的论点是：3D 数据本来就稀缺，不该让 3D 模型联合学这些。 做法是在 3D 生成之前先把可见证据翻译成 native material observations（用预训练材质 VAE 编码、与生成目标同 latent 空间、可直接解码），再围绕这个已落地的证据组织全表面补全。

SECTION 01 · TAKEAWAYS

先把结论读完

共 9 条。第 1–4 条出自论文，第 5–9 条是本站读完全文（含附录 A–H 与全部表格）后的判断，不是论文原话。

结论 01 · 核心论点

三件异构的事不该压在一个 3D 生成器身上

现有方法让 3D 模型同时做：① 从视觉特征推断 PBR 属性；② 在对应表面位置重建参考细节；③ 合成未见区域材质。论文的核心判断是——3D 训练数据本就稀缺，联合学这些异构任务会加重学习负担。应把 ① 卸载给 2D 先验、把 ② 交给相机投影显式对齐，只留 ③ 给 3D 模型。

结论 02 · 关键手段

喂进去的是材质观测，不是视觉特征

把参考视图的 PBR 估计投影到可见表面，用预训练材质 VAE 编码器压成 latent——它与生成目标共享 latent 空间、且能被预训练解码器直接解码。这叫 native observation latents。差别在于：视觉特征还需要 3D 模型"翻译"成材质，而材质观测已经是答案本身。

结论 03 · 一个容易忽略的细节

未观测区域不填零，而是直接省略

零填充会给缺失区域赋予具体语义（如黑色 albedo）。附录 E.3 给了实证：零填充版本让计算器背面近乎全黑、盘子红色侧面出现深色斑驳。本文利用编码器本身的稀疏坐标架构直接省略未观测体素。这个选择看起来小，影响很大。

结论 04 · 架构

只读锚点 + 交替更新：算力向"没有观测的地方"倾斜

观测流 O 全程只读（不出 query、不更新，只给每层供 K/V）；生成流 X 的查询坐标在 60 个 block 间交替——偶数块只 query 未观测 cells U，奇数块 query 全表面 S。结果：U 中的状态被更新 60 次，S_o 中只有 30 次。附带收益是 query token 少了 17.5%，采样快 1.20×。

结论 05 · 本站 · 消融读法

交错了不起的那点增益：0.02 dB

Table 5：Ours 的 shaded PSNR_fg 在 DTC-Tex 上 22.34 vs Joint-update attention 22.32（+0.02），Complex-Tex 上 20.64 vs 20.63（+0.01）。论文的用词是 "matches"，很诚实。真正的差异在 albedo（+0.15 / +0.16 dB）、MR MAE 与 1.20× 的速度。所以"交错更新"主要是一个效率与材质属性的改进，不是 shaded 保真度的突破。

结论 06 · 本站 · 真正的证据在附录

Figure 10：300 步 vs 1500 步，差距 10.74 dB

同样初始化、同样训练数据：本文用 GT PBR 观测，Pixal3D⋆ 用对应的 shaded RGB 图像特征。step 300 时 29.46 vs 18.72 dB；step 1500 时 30.86 vs 20.89 dB，SSIM 0.9938 vs 0.9557，LPIPS 0.00436 vs 0.03996。这才是"native observation 降低学习负担"最有力的证据——但只在 TeaPot 单个物体上做，且论文自己声明没有隔离架构与优化差异。

结论 07 · 本站 · 瓶颈在哪

2D 材质估计本身只有 ~19–20 dB

附录 D.1：F_2D 独立评估的前景 PSNR 只有 19–20 dB，论文直言"these results do not establish near-ground-truth observation accuracy"。而换成 Oracle PBR 能再带来 2.31 / 1.12 dB（shaded PSNR_fg）。换更强的 2D 先验（Qwen-Image-2.1，即 Ours‡）把差距缩到 0.98 / 0.47 dB。下一步的收益明显在 2D 侧。

结论 08 · 本站 · 商业对比的两处口径

我们用了双视图，商业系统只用单视图；且 VLM 与人类结论打架

Table 4：Hi3D 3.0 的 VLM Align 得分 8.19 高于我们的 8.08，但人类偏好只有 51.1%（接近抛硬币）——论文没有讨论这个矛盾。另外商业对比时我们额外合成了背面视图做条件，而商业系统只收到原始参考图，论文说明了但不改变"不完全对等"的事实。

结论 09 · 本站 · 定位

它是 TRELLIS.2 生态上的一次"分工重构"

几何与材质 latent 都用 TRELLIS.2 的 O-Voxel 表示与稀疏 VAE，自注意力也从 TRELLIS.2 初始化。本文没有换底座，而是重新划分了 2D 与 3D 的职责。这与本站 Channel Match 页（TRELLIS.2 少步蒸馏）共享同一底座，两页可以对照读。

SECTION 02 · MOTIVATION

两条路线的共同病灶：3D 模型被迫"猜材质"

理解 SUPRA-Tex 的关键，是看清它移走了什么——不是换了个更强的网络，而是把两件本不属于 3D 模型的事搬走了。

路线 A
多视图合成 → 投影融合
Hunyuan3D / MVPainter / MV-Adapter 一系。跨视图不一致会产生接缝与鬼影；把冲突预测做混合会模糊锐利的参考细节——而那些细节正是"超对齐"要保的东西。
路线 B
原生 3D 生成 + 图像条件
TRELLIS.2 用 3D 材质 VAE 把表面 PBR 压成 latent 再生成。其图像 cross-attention 不提供图像细节与 3D 表面位置的显式对应，模型得自己学细节该放哪。
路线 C
显式空间对齐的图像特征
Pixal3D / CUPID 把高分辨率图像特征按相机投影搬到 3D。对应关系是有了，但条件仍是视觉特征而非材质观测——3D 模型还是得先把它翻译成 PBR。
本文
先落地材质观测，再补全
把可见材质估计与表面对齐从 3D 生成中分离出去，交给 2D 先验与相机投影；3D 模型只负责"锚定已有证据 + 补全未见表面"。容量集中在真正需要生成的地方。
论文原话的精准表述值得引用："Rather than forcing the 3D model to infer physical materials from abstract visual features, this formulation enables the generator to anchor directly on established material evidence, preserving reference details while focusing more of its capacity on completing unobserved surfaces." 来源：Section 1 Introduction
图：三阶段流水线。中间那一步是本文的原创贡献所在。
SECTION 03 · STAGE 1

图 → 材质：把光照从材质里分离出来

第一步就把"光照分离"做掉，后面 3D 模型看到的才是物理材质而不是一张带阴影的照片。

设计单步、联合、全分辨率

FireRed-Image-Edit-1.1 适配而来

模型 F_2D 一次前向同时预测 albedo、metallic-roughness (MR) 与辅助的 normal。为复用 3 通道预训练图像 VAE，把 m 与 r 和常量通道打包成 3 通道图——顺带也满足了预训练材质编码器的输入格式。

推理 1.2 s（单张 H800），1024×1024 输出，无需迭代去噪。

机制factorized modality-axis joint attention

在 block 29 / 39 / 49 / 59 插入，rank 256，4 头

把 batch 维折叠，让 albedo / MR / normal 三条流并行处理，再在相同空间坐标上跨模态轴交换特征。这样既协调了通道间预测，又保留了预训练图像先验。

代价：只在 4 个 block 上做跨模态交换，交互密度有限。

SECTION 04 · STAGE 2 ★

原生观测编码：本文真正的原创贡献

三个设计决定合起来才成立：投影要过滤、未观测区域不填零、还要把"观测到什么程度"也编码进去。

1过滤后的表面投影

每个前景像素 u 经相机投影 π 关联到第一个可见表面命中点 p。推理时再加两道过滤去除不可靠边界对应：

  • 前景掩码腐蚀：去掉轮廓上的混合像素
  • 局部深度不连续过滤：邻域可见深度差超阈则拒绝（小投影误差就会把观测挪到别的表面上）
所有材质通道共享同一保留下来的观测支撑。

2不填零，直接省略

零填充会给未观测区域赋予具体材质语义（例如黑色 albedo）。

附录 E.3 的实证：零填充版本下计算器背面近乎全黑且残留正面的字符，盘子红色侧面出现深色斑驳；本文的 observed-support-only 编码则产出绿色背面、保住红白配色。

代价：必须依赖编码器的稀疏坐标架构。

3空间元数据

一个 latent cell 聚合多个表面体素，单视角很少能全覆盖。所以要告诉生成器"这个 cell 观测得有多全、离未观测区多近"：

ρ_s = |V_s ∩ V_o| / |V_s| 覆盖率 d_s = min dist_GS(s, q) 六邻域图上的边界距离，不可达则 −1
覆盖率用去重后的体素集合算，避免重复像素投影抬高数值。
一个容易漏读的限定：论文明确说明 ρ_s 与 d_s 描述的是观测的范围，不是 2D 估计的准确度。 另外，S_o（有观测的 cell）里的 cell 也可能含有未见体素，所以 U = S \ S_o 指的是"完全没有任何观测的 cell"，不是"所有未见表面"。引用口径时要注意。

Partial 编码 ≠ Complete 编码的一个切片（Figure 5）

共用同一个编码器，并不代表"部分观测"能得到"完整材质 latent"的对应切片。论文用 GT 几何 / 相机 / PBR（绕开 2D 预测与流生成）在 Complex-Tex 上隔离验证： 标准化 latent RMS 平均 0.713（95% bootstrap 区间 0.684–0.742，中位数 0.680），而同一输入重复编码的差为 0。 解码重建的三个例子（10th / 50th / 90th 百分位）full/partial PSNR 分别为 43.39 / 29.67、40.68 / 26.52、27.41 / 24.37 dB。

论文对这张图的自我限定很到位："These three examples demonstrate decodable material content with imperfect fidelity; they are not a cohort-wide reconstruction estimate." 也就是说——部分编码确实改变了表示，重建可用但不完美，且这三个例子不能当整体估计。
SECTION 05 · STAGE 3 ★

交错流 Transformer：只读锚点与交替更新

对比 Pixal3D⋆ 的做法（把投影图像特征通过加性残差注入、每层更新所有表面 token），本文改了两件事：观测只读，查询坐标交替。

训练目标（式 9–10）

Z_t = (1 − t) Z_gt + [σ_min + (1 − σ_min) t] ε σ_min = 10⁻⁵ v* = (1 − σ_min) ε − Z_gt L_FM = 𝔼[ MSE( v_θ(Z_t, t; O, G), v* ) ]

损失包括观测坐标在内的所有有效 token——也就是说，生成器被要求在有观测的地方也要能重建出完整材质，而不只是补全空洞。 观测表示不沿流路径加噪，始终作为条件输入。

训练时以 3% 概率丢弃整个观测条件（保留几何条件），避免模型把观测当成必然存在的东西。训练时间采样 t = sigmoid(ξ)，ξ ~ N(1,1)。

SECTION 07 · 实验二 / 三

SECTION 09 · 局限

论文 4 条 + 本站补充 5 条

前 4 条出自第 5 节 Limitations（含 Figure 6 的失败案例），后 5 条是本站判断，不是论文原话。

论文原文 01

图像与几何差异过大时，观测会落到错误的表面位置

端到端用 Pixal3D⋆ 预测的几何。形状或位姿差异大，投影的材质观测就会错位。对应过滤能去掉一部分不可靠观测，但无法修正底层的几何——而几何在材质生成期间是固定的。

论文原文 02

上游几何在未见区域的"幻觉结构"去不掉

即便可见形状对得上，Pixal3D⋆ 也可能生成不可信的未见结构。SUPRA-Tex 的条件是固定几何，无法移除这些结构，只能让它们的存在降低最终资产质量。

论文原文 03

跨可见性边界的补全会不一致

文字或图案延伸到可见区之外时（例如罐身上只露出一半的字母），模型可能保住了可见片段，却无法把笔画与布局连贯地延续到背面。

论文原文 04

2D 材质估计错误会被保留下来

例如给非金属的漆木表面赋了高 metallic。3D 生成器会保留这个错误，在渲染或重光照下产生不合理的反射。"准确传递参考细节"不等于"正确分解材质"。

论文原文 05 · 诚实度

失败案例没有做对照实验

论文明确："These are qualitative cases, without corrected-geometry controls or measured unseen-surface ground truth." 也就是说 Figure 6 展示的是现象描述，不是量化归因。同一段还提到背面视图可能改善最后一例，但"we report no paired two-view result"。

本站 06

交错架构的独立贡献被高估了

见第 ⑧ 节：vs Joint-update attention，shaded PSNR_fg 只差 0.02 / 0.01 dB。真正的差异化在 albedo、MR MAE 与 1.20× 速度。引用"交错流 Transformer"时应说清它带来的主要是什么。

本站 07

优势集中在"看得见的地方"

Table 2：DTC-Tex 参考视图领先 +3.54 dB，新视图只有 +1.76 dB；Complex-Tex 是 +2.87 与 +1.09。这正是 super-alignment 设计的预期结果，但也意味着未见区域的补全优势要小得多——它仍是生成问题，不是对齐问题。

本站 08

MAE 口径不是物理线性误差

附录 D.1 明确：metallic / roughness MAE 是在存储的 PNG 编码上计算的，测的是编码值差异而非物理线性材质误差。跨论文的 Met./Rough. MAE 数字不能直接比。

本站 09

算力门槛，与同组工作的定位

3D 生成器 30,000 步、global batch 576、64 GPUs——这不是小团队能复现的规模（对比同组 Gate3DGen 的 32 GPU / 15,000 步）。好消息是代码与权重已开源。与 Gate3DGen（同一批作者、同一 supra-3d 项目页）构成上下游互补：一个管"输入该不该修"，一个管"材质怎么落位"。

一句话总结。SUPRA-Tex 的价值不在"又一个更强的纹理模型"，而在于它把一个常被默认的前提拆开重新问了一遍： 3D 生成器真的需要自己从视觉特征里推断材质吗？ 答案是把材质估计交给 2D 先验、把对齐交给相机投影，只留补全给 3D 模型——然后用一个与生成目标同 latent 空间、可直接解码的原生观测把两者接起来。 证据链里最硬的一条不在主表，而在附录 Figure 10：300 步就到 29.46 dB，而视觉特征条件化的对照 1500 步才 20.89 dB。 限制也很清楚——它建立在 TRELLIS.2 的几何与材质 VAE 之上，几何错了材质就跟着错，而 2D 估计本身还只有 19–20 dB，离 Oracle 还有 2 dB 的空间。
