几何全对，纹理却烂了
Channel Match：少步 3D 生成里那个「看不见的」latent 分布漂移

这篇论文做了两件事：把 TRELLIS.2 的 1024 shape flow 蒸馏到两步（shape sampling 快 4.5×），以及——更重要的——发现了这个蒸馏带来的一个此前没人报的失败模式。 少步采样会让 shape latent 的逐通道标准差坍缩：几何完全正确，但 latent 已经偏离训练分布； 而冻结的 PBR 纹理阶段只在 in-distribution latent 上训练过，于是产出错误材质——在几何合法的资产上出现深色斑块。 论文对此的原话很准："texture artifacts that resemble structural defects"——这些瑕疵看起来像结构缺陷，但几何其实是好的。 修法是 Channel Match：一个免训练的逐通道仿射校准，只用离线算一次的 (μ̂, σ̂)，插在 shape flow 与 texture flow 之间，不修改任何一个模型。

SECTION 01 · TAKEAWAYS

先把结论读完

八条，其中第 3–8 条是本站读完全文（含 Limitations）后的判断，不是论文原话。

结论 01 · 诊断

最值钱的是那个失败模式，不是加速方法

"几何完全正确，但 latent 统计漂移导致冻结的纹理阶段产出错误材质，瑕疵看起来像结构缺陷"。这个坑极阴险——你会去查几何模型，实际病因在 latent 分布。

结论 02 · 工程相关性

这不是实验室奇观，是真实部署会踩的坑

「只蒸馏 shape flow、纹理模型冻结」恰恰是工业上最自然的做法（纹理模型贵、不想重训）。而这个漂移会救 naive 少步采样（teacher@2 FD 15.67→15.21），所以不绑定蒸馏——只要你把步数压下来就可能中招。

结论 03 · 机理

漂移是标准差的坍缩，而且是单边的

latent 逐通道标准化后 σ̂_c = 1，采样得到的通道 std 只会低于训练值。所以坍缩分数 S = mean_c max(0, σ̂_c/σ^s_c − 1) 是个方向明确的标量，也解释了为什么不考虑 mean-only 变体——漂移的形态就是 std 坍缩。

结论 04 · 数据细节（本站）

Teacher@12 的 S 也有 0.150，不是零

Table 6：12 步 teacher 的坍缩分数 0.150、16.8% 通道 std < 0.8；两步学生 0.174 / 22.4%；一步 0.207 / 28.4%。所以这不是「少步独有」的病，而是「少步会放大」的病。论文表述为 few-step failure mode，数据上更准确的说法是加剧了一个本就存在的基础漂移。

结论 05 · 最易被误读的表

Table 4：在简单资产上 full match 比什么都不做还差

全 Toys4K 上，student@2 的 FD-Incep：none 14.09 / std-only 13.88 / full 14.16。只有 std-only 是安全的。所以「Channel Match 一律开 full」是错的。选择依据是坍缩严重程度——而 S 门控只决定「开不开」，没决定开哪种形式，论文没给按 S 选形式的方案。这是个真实缺口。

结论 06 · 数字口径

「4.5×」是 shape sampling，端到端只有 1.5×

shape sampling 5.29→1.18 s（4.5×），但 image→shape 端到端 11.51→7.55 s（1.5×）——被冻结的 sparse-structure prefix 和纹理阶段限制住了。摘要里两个数字都有，但只报 4.5× 有标题党风险。

结论 07 · 泛化（本站）

凡「前一阶段 latent 直接作为后一阶段条件」的流水线都有这个风险

TRELLIS.2 的 texture flow 是以 shape latent 为条件的，所以 shape latent 一漂，纹理模型就见到 OOD 输入。这不只 TRELLIS.2 的问题——Hunyuan3D、Sparc3D 这类多阶段原生 3D 流水线同理。把同样的校准扩到纹理阶段论文明确留开放（Sec. 6）。

结论 08 · ULIP 第三次失灵

ULIP 跨 0.04，FD 跨 20——又一次印证自动指标分辨力弱

Table 1：ULIP-I 从 teacher@12 的 38.45 到 ours@2 的 38.48 到 ours@4 的 38.49，跨 0.04；而 FD-DINOv2 从 106.66 到 127.44，跨约 20。这是本站第三次看到 ULIP 对这类差异不敏感（前两次是 DHO 与 GATOR）。别拿 ULIP 做这类消融的主指标。

SECTION 02 · SETUP

TRELLIS.2 三阶段流水线，与「只蒸馏 shape flow」的代价

理解失败模式的前提：shape latent 不只是几何的编码，它直接是纹理阶段的输入。

图 1：TRELLIS.2 流水线与 Channel Match 的插入位置（对应 Algorithm 1 下半段）。❄ = 冻结。

为什么「结构化稀疏 latent」让蒸馏难做难点 1

现有连续时间蒸馏方法主要为稠密固定维度表示设计。原生 3D 依赖稀疏、变长的结构化 latent——这是扩到高分辨率的必要条件，但让一致性目标里速度方向导数的计算变困难。

为什么 3D 比 2D 蒸馏更难难点 2

中间 latent 接口被多个阶段共享：几何 latent 是下游外观合成（PBR 纹理）的输入，而图像生成里 latent 直接解码成像素。所以减少步数可能在保留几何结构的同时把 latent 统计推离下游生成器期望的分布——这是一种几何评测看不见的质量退化。

为什么不用 2D 那套判别器难点 3

distribution-matching / 对抗蒸馏那一族依赖 2D 图像判别器，但原生 3D latent 的质量评估需要不可微的渲染，信号很难拿到。所以本文走速度空间的连续时间自一致性 + 真值速度锚定。

SECTION 03 · DISTILLATION

少步蒸馏：两个速度空间损失 + 自适应权重 + 一个 JVP 内核

学生从教师初始化，只蒸馏 1024 shape flow。三个组件各自解决一个具体问题。

3.1 真值速度回归（式 3）：锚定「数值」

Lgt = Ex₀,ε,t ‖ vθ(xt, t) − [(1 − σmin)ε − x₀] ‖²₂　← 目标就是式 2 的解析瞬时速度

它的最小值就是真实的边缘场，所以固定了学生应该取的数值。放在速度空间而非样本空间，避开了样本空间重建在小 t 处的加权病态。单靠它得不到少步采样器——它的作用是让下一个损失不至于收敛到一个「一致但不正确」的传输场。

3.2 连续自一致性（式 4–7）：让场与步数无关

g(xt, t) = d/dt vθ(xt, t) = ∂tvθ + (∇xvθ) v̄φ(xt, t)　← 式 4：沿教师轨迹的全时间导数；传输方向是教师速度
r = ‖g‖ / (κ · med‖g‖)　，　ĝ = (tanh r / r) · g　← 式 5：平滑、保幅值的鲁棒 cap（κ = 4 × running median）
v* = sg( ṽθ(xt, t) − η ωt ĝ )　，　Lscm = E ‖ vθ − v* ‖²₂　← 式 6–7：ṽθ 是 EMA 学生

三个容易踩的实现细节工程

  • 一次 forward-mode 拿两项：latent 的 dual tangent 用 v̄φ 播种得空间项；time 输入的 dual tangent 播种常数 1000（骨干消费 scaled time 1000t）得 ∂tvθ。省略时间项、或空间项用非教师速度播种，都会使 tangent 有偏。
  • 为什么用 tanh 而非 unit-norm：r→0 时 scale→1（保留小切线，g→0 时修正自然消失）；r→∞ 时 token 范数饱和在 κ·med‖g‖ 附近。unit-norm 归一化会把小的一致性信号一起抹掉。
  • 锚点用 EMA 学生而非教师：教师值同时当「目标」和「传输方向」会产生有偏不动点。

自适应损失平衡（式 8）免手调

两个损失的尺度不同且随 t 变化。不手调 per-t schedule，改用 uncertainty weighting：对每样本损失 ℓ 与可学习标量 w(t)，加权项为 ℓ·e−w(t) + w(t)，其最优解 w*(t) = log ℓ 自动在时间上归一化。

w(·) 用一个小型 Fourier-feature MLP 实现并联合训练，两个项各用一套。

效果：省掉了「两个损失权重怎么调」这一步——这在双目标蒸馏里通常是最费时间的。

3.3 JVP FlashAttention 内核：让连续目标在高分辨率上装得下

式 4 是 Jacobian-vector product，需要 forward-mode 穿过每一层包括 attention。Stock FlashAttention 只返回 primal 不返回 tangent，会丧失高分辨率稀疏 latent 上的内存优势。本文实现了一个 fused Triton 内核：给定 packed QKV 的 primal 与 tangent，单次 fused pass 返回 primal output + tangent，并 patch 骨干的变长 attention 入口。

SECTION 04 · THE FAILURE MODE ★

sampling-induced latent distribution drift

这是本文最重要的贡献。加速只是手段，发现并解释这个失败模式才是。

"…aggressive sampling reduction can introduce distribution shifts in the geometry latent that preserve geometric completeness but violate the latent interface with downstream appearance synthesis, causing texture artifacts that resemble structural defects." —— 摘要「贡献」第一条

症状看得见

PBR 渲染上出现深色 / 斑块状（dark / blotchy）瑕疵，材质明显不对。

但把纹理剥掉看网格——几何是完整的、正确的。

病因看不见

加速后的几何采样器产出结构上有效的 shape latent，但逐通道统计量偏离训练分布。

冻结的 PBR 纹理阶段只在 in-distribution latent 上训练过 → 见到 OOD 输入 → 合成错误材质。

为什么阴险诊断

瑕疵看起来像结构缺陷，所以你会去查几何模型、查蒸馏损失、查步数——但几何从头到尾都是对的。

论文用「几何简单的样本」做受控实验（图 1），单独隔离出 latent 漂移的效应。

漂移的形态：逐通道标准差的单边坍缩

只见过这个 少步采样得到 μˢ σˢ < σ̂　← 坍缩 几何仍正确，但 OOD Channel Match 校准后 回到训练分布 纹理阶段正常 坍缩分数 S = (1/C) Σc max(0, σ̂c/σˢc − 1)　← 漂移是单边的（σˢ 只会偏低），所以 S 是一个方向明确的标量度量

SECTION 05 · CHANNEL MATCH ★

修法：一个免训练的逐通道仿射映射

核心卖点很朴素：只用离线算一次的数据集级统计量，不修改任何一个模型。

式 9：校准公式

x′c = μ̂c + ( xc − μsc ) · [ 1 + s ( σ̂c / σsc − 1 ) ] 　← 对每个通道 c 独立做
　(μ̂c, σ̂c)：训练集所有 active token 上通道 c 的均值与标准差，离线算一次
　(μsc, σsc)：当前生成 latent 的 active token 上同样的两个量

两种形式s 的选择

full（s = 1）：同时对齐均值与标准差。

std-only：只对齐标准差，保留资产自身的均值。

不考虑 mean-only——因为观测到的漂移形态就是标准差的坍缩（Table 6）。

性质为什么好用

只用数据集级统计量 → 免训练（training-free），不修改任何一个模型。

是逐通道仿射映射，推理时就是一次 in-place 变换，成本几乎为零。

局限：不建模通道间相关性（论文 Sec. 6 自认，full-covariance 或 grouped 变体可解）。

插入位置Algorithm 1

在蒸馏后的 shape flow 与冻结的 texture flow 之间，单步 in-place。

共享的 prefix 与纹理阶段完全不变。

式 10：自适应门控（不需要 ground truth）

S = (1/C) Σc max( 0, σ̂c / σsc − 1 )　，　仅当 S > τS 时应用校准（默认 τS = 0.20） 　← S 只用采样出来的 latent 自己算，所以推理时不需要 ground truth

漂移依赖步数，所以用坍缩分数门控。因为 latent 已逐通道标准化（σ̂c = 1），漂移是单边的，S 就是对「采样通道低于训练 std 的 deficit」的直接求和——它同时是漂移的诊断量，也是门控信号。这个设计很干净。

Algorithm 1 · 生成（含 Channel Match） 输入：图像 c；冻结 prefix、texture flow、decoder D；蒸馏后的 vθ；统计量 (μ̂, σ̂)；阈值 τS；步数 K 1 S ← sparse structure(c)；上采样到 1024 坐标 // 共享 prefix 2 x ← 在这些坐标上从噪声出发做 vθ 的 K 步 Euler 积分 3 计算坍缩分数 S ← (1/C) Σc max(0, σ̂c/σˢc − 1) // 式 10 4 if S > τS then 5 x ← ChannelMatch(x; μ̂, σ̂) // 式 9，in-place 6 end if 7 y ← texture flow(x, c)；M ← D(x, y)；return M

SECTION 08 · ABLATIONS

消融汇总

本文消融不多，但每一条都直接对应一个设计选择。

① 校准形式Table 4

std-only 在简单 Toys4K 上安全且略优；full 在瑕疵密集的演示资产上帮助最大。取决于坍缩严重程度。

门控未覆盖「开哪种形式」。

② 门控阈值Table 5

τS 从 −∞ 到 0.27 扫过：一旦覆盖 ≥75% 资产，三个指标基本平。

对 τS 不敏感；默认 0.20 给最好的 LPIPS 与 PSNR；always-on 是安全兜底。

去掉自一致性：场正确但不与步数无关，两步时急剧退化。

两个损失互补，缺一不可。

④ JVP 内核Table 7

SECTION 09 · LIMITATIONS

局限：论文自己列的五条 + 本站的四条

前五条来自 Sec. 6 Limitations 原文。

1 只蒸馏 shape 阶段

端到端加速被冻结的纹理采样器限制住（4.5× → 1.5×）。蒸馏纹理阶段是直接下一步。

Sec. 6 原文。

2 CM 不合成新的几何细节

它只修 per-channel 分布漂移，不增加几何细节，所以四步学生在几何敏感指标上仍最强。

Sec. 6 原文。

3 逐通道仿射 → 忽略通道间与空间结构

作为 per-channel affine map，它不建模通道间相关性，也不建模空间结构。full-covariance 或 grouped 变体可以捕捉。

Sec. 6 原文。

4 门控到 oracle 还有差距

坍缩分数门控已恢复大部分可用收益，但缩小到 GT oracle 的剩余差距仍是开放方向。

Sec. 6 原文。

5 把校准扩到纹理阶段未做

论文明确："Extending the same calibration to the texture stage is a natural next question we leave open."

Sec. 6 原文。这对做 PBR 的人其实是最值得追的一条——纹理阶段的 latent 也会有同样的漂移。

6 只在 TRELLIS.2 一个骨干上验证（本站）

1024³ 一个分辨率、TRELLIS.2 一个骨干。漂移是否在其他原生 3D 骨干（Sparc3D、Hunyuan3D）上同形态出现，没有验证。考虑到作者自己就是 Sparc3D 团队，这个泛化实验其实是有条件做的。

本站：结论 07 的泛化推断目前只是推断。

7 「开哪种形式」没有自动方案（本站）

表 4 显示 full 在简单资产上反向变差，但门控只管「开不开」。生产部署需要人工按数据集判断用 full 还是 std-only——这是个实打实的落地风险。

本站：最简单的补救是按 S 分段选形式，论文没试。

8 演示资产只有 72 个（本站）

Table 3 / Table 5 的关键纹理证据都建立在 n = 72 的 TRELLIS.2 演示资产上（且是瑕疵密集的挑选样本）。全 Toys4K 上的结论（表 4）反而是「full 略差」。引用 LPIPS 0.0742 这类数字时要带上"在瑕疵密集子集上"这个前提。

本站：这个 n 与「瑕疵密集」的挑选，是全文最需要提防的一处。

9 JVP 内核细节在补充材料（本站）

正文只有一段 + Table 7，"full kernel implementation in the supplementary material"。复现需要等补充材料。另外 Table 7 只在 N=15,000 测，生产长度 30,000 只说了"仍能跑"没给数。

本站：这个内核是让整套方法可用的关键，可复现性暂时存疑。

一句话总结。 如果你想从这篇带走一样东西，应该是那个诊断而不是那个加速方法： 在多阶段原生 3D 流水线里，把某一阶段的采样步数压下来，可能在几何完全正确的情况下，通过 latent 分布漂移把下游冻结阶段搞坏——而且坏出来的样子像结构缺陷，极易误诊。 修法便宜得离谱（一次离线算统计量的逐通道仿射，不碰任何模型），而且对 naive 少步采样同样有效，所以不绑定蒸馏。 两个提醒：① 报「4.5×」要说是 shape sampling，端到端只有 1.5×；② full match 不是无条件更好——在坍缩轻微的简单资产上它比不校准还差，std-only 才是安全默认。
