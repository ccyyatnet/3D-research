Line Primitives IR：用完全不透明的线段
重建毛发 · 纤维 · 织物

Inverse Rendering for Modeling with Line Primitives 用不透明线段基元填补了 3D 表示里长期空着的一格： 既有显式几何（能进 z-buffer 管线），又有模糊外观（能表达毛发）。关键在于半透明观感不来自 alpha 混合， 而来自「2× 亚像素栅格 Bresenham 画线 + 高斯重建滤波」的聚合效应 —— 因此无需按深度排序， 光栅化、深度测试、硬件加速、物理仿真全部接得回来。

Section 01 · Bottom Line

结论先行

如果只有三分钟，看这四张卡。

结论 01

半透明是「滤」出来的，不是「混」出来的

每个线段完全不透明。渲染时先在 2× 亚像素栅格上用 Bresenham 画线，再用高斯重建滤波器 （σ=0.5 px，截断半径 1.5 px）聚合成最终像素。大量亚像素宽的不透明细线密集排列，滤波后自然得到半透明的模糊观感。

结论 02

不透明 → 免排序 → 标准管线全部接回

3DGS 的半透明靠连续 alpha 混合，必须严格按深度排序，于是 z-buffer 用不上，反射建模、物理仿真、几何编辑都难接。 本文基元不透明，z-buffer 直接可用 —— 这是全文价值的因果链起点。

结论 03

最精巧的设计：前向 6×6，反向 2×2

加抗锯齿后像素颜色由滤波核内多 fragment 联合决定，log 概率梯度失效。作者拆成 per-fragment 求和后， 因远离中心权重极小、梯度噪声过大，只在 2×2 最近邻上求 opacity 梯度。 刻意的不对称，作者自己也承认是近似。

结论 04

代价：PSNR 输 0.64、内存 3.5 倍

四个指标里唯一输的是 PSNR（37.09 vs 37.73）；内存 409 MB 是 3DGS 的 3.5 倍， 源于 2M 顶点 × per-vertex SH 3 阶。降 SH 阶数能缓解，但会直接砍掉视角相关外观，不是免费的。

⚠️ 一个必须先纠正的信息：这不是普通 arXiv 预印本，而是 ACM Trans. Graph. 45(6), Article 200（SIGGRAPH Asia 2026）， 已过同行评审，DOI 10.1145/3842527；arXiv 上只是作者自存档版本。 而且它是同组 DiffSoup [Tojo et al. 2026]（三角形版随机可微光栅化）的直接续作 —— 本文把那套 machinery 从三角形扩展到了线段。
Section 02 · Positioning

要解决的问题：3D 表示里空着的那一格

表面网格与体积表示各占一头，中间「显式几何 + 模糊外观 + 能进标准管线」这一格长期是空的。

图 1：本文补的是「显式几何 + 模糊外观 + 能进标准管线」这一格

为什么两边都不行

表面网格的假设失效

它假设「几何局部光滑 + 细节可参数化进贴图」。而毛发、毛皮、纤维、织物的特点是 边界本身模糊，外观由大量细元素的聚合涌现。用表面硬套要么糊掉，要么得靠昂贵的过程化细节生成。

体积表示放弃了显式结构

能抓模糊边界，但半透明靠连续 alpha 混合，必须严格按深度排序（3DGS 的 back-to-front）： 标准深度测试用不上、反射建模与物理仿真难接、跨平台部署受限于特定渲染路径。

为什么是线段（1D），不是点或三角面

All points0.105太稀疏，撑不起密集纤维结构

Section 03 · Method

技术拆解：五个关键设计

从场景表示，到如何让离散深度测试可微，再到全文最精巧的前向/反向不对称滤波。

3.1 场景表示（§4.1）

  • 顶点位置 V = {v_v}，v_v ∈ R³；边索引 E = {e_e}，e_e = (v¹_e, v²_e)
  • 每顶点辅助属性 A_v：可学习特征、几何量（如切向）或组合；本文用 per-vertex 球谐（SH）至 3 阶做视角相关外观
  • 每条边一个 opacity α_e ∈ [0,1]，表示「这条边存在的概率」—— 这是在优化中让基元出现 / 消失的关键，对缠绕结构（tangled）的鲁棒性很重要

3.2 随机可微光栅化：如何让离散深度测试可微（§4.2）

核心障碍被遮挡的基元完全拿不到梯度

不透明基元的最终像素颜色由最前的 fragment 决定（式 1，f* = argmin_f d_f）。 这是离散 argmin，梯度无法回传到被遮挡的基元。

DiffSoup 的解法（本文沿用）：给每基元连续 opacity → 每次渲染随机激活 → 似然比估计器取梯度。

步骤 1–2连续 opacity + 随机激活

给每个基元一个连续 opacity α_f（优化为连续值，最终收敛到 0 或 1）； 每次渲染随机激活：α_f > τ_f，τ_f ~ U[0,1]（式 2）。 测试时 τ_f 统一设为 0.5。

步骤 3选中概率（式 3）
pf = αf · ∏f′ ∈ F: df′ < df (1 − αf′)
结构与 alpha 混合的 transmittance 项同形，但不需要排序 —— z-buffer 直接算。
步骤 4似然比梯度估计器（score function / REINFORCE，式 4）
∇L = 𝔼pf[ ∇L₁(Cf) ]  +  𝔼pf[ L₁(Cf) · ∇log pf ]
第一项：常规颜色 / 位置梯度。
第二项：存在性梯度 —— 决定这个基元该不该存在。
log 概率梯度可无排序求值（式 5）：∇_{α_f} log p_f = 1/α_f（自身），= −1/(1−α_{f′})（更靠前的 fragment），其余为 0。

3.3 线宽问题的规避：故意不参数化

现有方法要么用世界空间管半径，要么用屏幕空间描边宽度。两者都面向稀疏的 stroke-based 表示， 而本文面向亚像素宽度纤维的密集排布，带来两个难题：① 前向反向都必须极高效（基元数量巨大）； ② 线宽小于 1 像素时优化本质欠约束，容易不稳，且从抗锯齿后的像素颜色反推宽度需要海量采样，欠采样会产生虚线伪影。

本文的选择：Bresenham（1965），根本不设线宽

在 2× 亚像素栅格上光栅化，靠后续抗锯齿产生平滑滤波外观。亚像素覆盖一致 → 规避宽度优化的不稳定；无欠采样虚线；极高效且有广泛硬件支持。

位置梯度借用 microedge [Pidhorskyi 2024]：把 Bresenham 产生的轴对齐 fragment 边当作「代理轮廓边」，得到稳定梯度。

3.4 前向 / 反向的不对称滤波设计（全文最精巧处）

加抗锯齿后，像素颜色不再由单个 fragment 决定，而是滤波核支撑域 N 内多 fragment 的联合贡献。 式 (4) 的 log 概率梯度失效，变成（式 9）：

∇αf L = 𝔼pN[ L₁(Ĉ) · ∇αf log pN ]
联合概率 pN 一般不可解 → 独立性假设下拆成 per-fragment 求和（式 10）。但直接用式 (10) 有两个坑。
坑 1同一基元内部的 fragment 不独立

基元内部 opacity 恒定，per-fragment 梯度会产生不一致信号 —— 比如鼓励线的一端低 opacity、另一端高，等价于「把线缩短」。

→ 化解：几何变化交给位置梯度（移动顶点），opacity 梯度在基元内取平均，只负责「整体存不存在」。

坑 2远离中心的 fragment 梯度噪声极大

远离像素中心的 fragment 滤波器权重极小，单次随机采样下梯度噪声过大。

→ 化解（式 11）：只在像素中心所在的 2×2 最近邻 fragment 上求 opacity 梯度。

图 2：前向 6×6 高斯 / 反向 2×2 box —— 作者自承是近似，并把「更有原则的方差缩减（control variates）」列入未来工作

3.5 Adaptive re-lining（§4.3）：离散拓扑的「外科手术」

连续梯度不够 —— 初始化是杂乱短线段，得让它们「长成」连贯折线。每 100 次迭代做一轮离散更新：

1Prune

删掉低 opacity 或过短的边。

2Merge

把距离在长度阈值内的折线端点接起来，形成连通折线。

3Split

把长边拆开，直到达到目标顶点数（顶点属性占内存大头，要用满预算）。

PSNR 为什么输

作者解释：GT 是超高分采样率路径追踪出来的「极端光滑边界」，离散几何聚合略逊。这个解释合理 —— PSNR 惩罚高频误差，而密集细线本身就是高频。 但也要注意：PSNR 输而 SSIM / LPIPS 赢，通常意味着「更锐但像素级对齐略差」，视觉上未必是坏事。

内存 3.5 倍从哪来

2M 顶点 × per-vertex SH 3 阶（16 系数 × 3 通道）。论文说「未针对总内存优化」，可通过降 SH 阶数缓解 —— 但这会直接砍掉视角相关外观，不是免费的午餐。

Section 06 · Limitations

适用边界与作者自述的局限

这一节里藏着最容易误读的部分：它并不是「能重建任意场景里的毛发」。

适用边界（读实验设置才能看出来的）

  • 采集在暗环境 + 同轴闪光 + 偏振滤镜（抑制高光），SfM [Schonberger & Frahm 2016] 定位
  • 预处理假设全黑背景：低强度阈值 → 形态学闭运算保细结构 → 取饱和度总和最大的连通域
  • 初始化依赖 NeuS2 粗代理表面（论文说纯随机也行，但实测路径是 NeuS2）
  • 真实数据集 Fuzzy 是作者自采的（植物 / 织物 / 毛皮 / 水果）
→ 所以准确的说法是：「物体级、可控光照、黑背景下能重建毛发」，而不是「能重建任意场景里的毛发」。

作者自述的局限（§7）

  • 恢复完整拓扑（如严重遮挡的头发内部）需要更强先验或更丰富的采集
  • 像素尺度下几乎不可见的微观纤维朝向与连接，恢复不准
  • 手写连接规则 → 想换成学习的方向性连接概率
  • opacity 梯度的方差缩减（control variates）未做
  • 从亚像素观测恢复线宽本质上很难（但有价值）
  • 缺少 LOD：近距离会看到线段本体，需要 LOD 或 triangle–line 混合表示
最后一条最值得注意：它意味着近距离观看时这套表示会露馅，与「zero polygon-count cost 类方法的剪影问题」是同一类边界。
Section 07 · Takeaways

在领域里的位置与对我们的启示

与此前解读的 Luce 形成一组对照：一个在生成端，一个在重建端，指向同一个判断。

Luce本文（Line Primitives IR）
环节生成端重建端
目标让生成的资产带 PBR 材质、能进引擎让重建的产物是显式几何、能进引擎
共同判断3D 领域的瓶颈正从「能不能生成 / 重建出来」转向「产出物能不能进标准图形管线」

1「免线宽」是一次漂亮的问题重构

不跟欠约束的宽度参数死磕，而是换一条路：Bresenham + 亚像素栅格 + 抗锯齿滤波，让宽度从参数变成涌现结果。

同类思路可迁移到其它「参数难优化但观感可涌现」的表示设计上。

2随机化 + 似然比估计器是离散可微的通用钥匙

离散 argmin（深度测试）阻断梯度 → 连续 opacity + 随机激活 + score function 梯度。不透明 + 免排序 + 可微三者同时成立。

对比 3DGS：它为了可微放弃了 z-buffer；本文用随机化把两者都要了回来。

3「前向 / 反向不对称」是被低估的工程手法

前向 6×6 高斯保质量，反向 2×2 box 保梯度信噪比。前向和反向不必是同一个算子，只要梯度方向大致正确。

对自研可微渲染器很有参考价值 —— 不必强求「数学上严格对偶」。

4显式几何的红利是「下游可能性」，不是指标

PSNR 输了 0.64，但换来毛发 BRDF、物理仿真、Mitsuba 光追、移动端预览 —— 这些是 3DGS 给不了的。

评估「能不能进管线」的工作时，纯重建指标会系统性低估其价值。

一句话总结：3DGS 的可用性问题（编辑、仿真、光照编辑、跨平台）正在被系统性地逐个解决 —— 本文解决的是「模糊结构」这一最后难啃的角落。它和 Luce 一起说明：产出物能不能进标准图形管线，正取代「能不能生成/重建出来」成为新的瓶颈。
