别只把负样本推开，告诉它该去哪
DHO：给 flow matching 的负样本分支一个「归航场」

3D 生成的 RL 后训练大多是从 2D 视觉生成直接搬过来的：DPO-style 压低负轨迹似然、GRPO-style 降低负优势样本概率、NFT-style 沿负梯度反转速度。 这篇论文指出它们的共同点——都在把速度推离负轨迹方向，却从没说清楚应该朝哪去。 DHO（Dynamic Homing Optimization）把这个洞补上：先用 MAM（最小代价一对一匹配）给每个负样本分配一个确定的正样本作为目的地， 再用 TDC（时间感知动态修正）构造一条「剩余时间感知」的修正速度把它牵过去。 它是在前向过程插值上做策略更新的 forward-process RL，采样器随便换、不用存整条采样轨迹。 落到系统上就是 Flow3D-Pro：两阶段图生 3D 网格（Stage I 取自 Hunyuan3D 2.1、Stage II 取自 LATTICE）， 只对 Stage I 做 SFT → DHO 后训练，用 Gemini 3.1 Pro 当奖励模型、28 + 4 张卡做异步在线训练。

SECTION 01 · TAKEAWAYS

先把结论读完

五条最值得记住的，其中第 4、5 条是本站读完全文（含附录）后的判断，不是论文原话。

1负样本分支缺的不是「斥力」，是「目的地」

DPO / GRPO / NFT 三类目标在负样本上做的事，本质上都是让速度场别再生成这条负轨迹，然后把「往哪走」这件事全交给正样本分支。 DHO 反过来：给每个负样本显式指定一个正样本目标，并给出到达它的速度场。

为什么重要：3D 后训练受限于预训练模型能力、rollout 多样性和奖励分布复杂度，只靠「推开」的增益很有限——论文 Table 1 里 GRPO 的用户研究只到 3.02，DHO 到 4.02。

2两个组件缺一不可：MAM 配对 + TDC 牵引

MAM 用 Hungarian 算法做 batch 内最小代价一对一匹配（代价是 latent L2 距离，O(B³)），保证每个负样本拿到不同的正目标； TDC 用 v = (xw* − xtl)/(1−t) 把「剩余时间」算进来。

为什么重要：只做配对不做时间感知（静态动作 xw* − x0）会累积 t(xl − xw*) 的终点误差；消融里动态比静态的用户研究 0.69 vs 0.31，翻倍。

3正样本分支是「退化情形」，与标准 rectified flow 自洽

正样本集合自己做 MAM 会退化为恒等排列（对角代价为 0），于是目标就是它自己，时间感知场恰好塌回标准 rectified flow 动作 xw − x0（论文式 8）。 两个分支因此共用一个规则，不需要为负样本另写一套目标。

为什么重要：这说明 DHO 不是「加了一个新 loss」，而是把负样本分支纳入了同一个速度回归框架，只是插值端点换了。

4自动指标几乎不动，主观排序拉开一大截

Table 2 里 Flow3D-Pro-Base → Flow3D-Pro，ULIP 只从 0.143 → 0.150、Uni3D 0.350 → 0.360，而用户研究 5.64 → 8.64。 论文也明确「以 User Study 为主指标」。

本站判断：ULIP / Uni3D 这类 CLIP 相似度对「几何好不好」分辨力很弱，看这张表时不要被 ULIP 的小数点误导——真正的变化在主观排序里。反过来说，整篇论文的说服力高度依赖那套盲评流程（3 位专家 × 200 张图 × 方法匿名随机序）。

5Stage II 会放大 Stage I 的坏几何

Table 1 里一个容易被忽略的细节：DPO-style 过了 Stage II 之后用户研究不升反降（2.36 → 2.32），NFT-style 也从 3.07 掉到 2.80，而 DHO 从 4.02 升到 4.26。

本站判断：这恰好是「把后训练放在 Stage I、Stage II 冻结」这一设计选择的证据——精修阶段修不好 lifting 阶段的结构错误，只会把它固化。论文 Figure 5 的定性图（四根手指、火焰状额头、断掉的楼梯）也是这个意思。

6奖励模型是闭源的 Gemini，复现性要打折

奖励由 Gemini 3.1 Pro 给出：每个 mesh 渲染 6 视图 + 参考图，从重建保真度 / 几何合理性 / 朝向对齐三个维度打 1–5 分。 异步框架之所以必要，是因为这个 API 的延迟高且抖动大。

本站判断：工程上是对的（不然 28 张 rollout 卡会空转），但奖励随模型版本漂移，别人复现时拿不到同一个奖励分布；论文自己也把「奖励维度不够细」列为首要 limitation。

SECTION 02 · THE GAP

现有 RL 目标在负样本上做了什么

论文的诊断非常具体：三类目标机制不同，但在「如何对待负样本」上共享同一个缺陷。

DPO-style（Flow-DPO 等）
隐式压低负轨迹似然
通过成对偏好比对负样本降权，等价于把概率质量从负轨迹挪走，但没说挪到哪。
GRPO-style（Flow-GRPO 等）
降低负优势样本概率
把生成当在线 RL，对低奖励 rollout 施加惩罚；优势 A<0 就压，A>0 就强化。
NFT-style（DiffusionNFT 等）
沿隐负策略反转梯度
在前向过程上注入负速度空间梯度，把预测速度推离负轨迹目标方向。
DHO（本文）
给负样本一个归航场
先配对一个正目标 xw*，再用剩余时间感知的速度把它牵过去——目的地与到达方式都显式给出。

图 1（依论文 Figure 2 / Figure 3 重绘）：左边是三类现有目标在负样本上的共同行为——只产生「离开 x_l」的方向；右边是 DHO——MAM 先配对目标，TDC 再给出到达它的速度。

⚠️ 论文的诊断前提值得单独强调：它没有声称 DPO/GRPO/NFT 在 2D 上不行，而是说在 3D 上「受限于预训练模型能力、rollout 多样性、奖励分布复杂度」这三者，照搬的增益有限。 Table 1 里 SFT 之后 GRPO/DPO/NFT 的用户研究只到 2.36–3.07，而 DHO 到 4.02——差距主要出现在主观几何质量上。
SECTION 03 · METHOD

DHO 的两个组件

DHO 是一种 forward-process RL：策略更新发生在由 rollout 端点构造的前向插值上（噪声 → 负样本），采样器可换，也不需要把整条采样轨迹存下来。

① MAM：最小代价吸引匹配

在每个 mini-batch 的 latent 特征空间里，把负样本集合 Ñ 与正样本集合 P̂ 之间「谁去追谁」形式化成一个最小代价一对一分配问题： 代价就是两点的 L2 距离，求解用 Hungarian 算法，复杂度 O(B³)。

Ci,j = ‖xil − xjw‖22 （式 2 · 代价矩阵）
π* = arg minπ∈ΠB Σi,j Ci,j πi,j （式 3 · 线性求和分配）
xiw* = xπ*(i)w （式 4 · 每个负样本拿到唯一目标）

可以把它看成负/正 rollout 端点两个均匀经验分布之间的 mini-batch 最优传输。 一对一约束是关键：消融里 MAM 同时优于 random pairing、nearest-neighbor 和 soft attraction（对多个正样本做相似度加权聚合）。 论文给的解释是——soft 版本会保留一个弥散的多目标方向，而 MAM 给的是确定、单一的目的地。

样本怎么分组归一化优势

Ai = (ri − r̄) / sr （组均值 / 组标准差）
  • A > 0 → 正样本；A < 0 → 负样本；A = 0 直接丢掉。
  • 两边数量取小者 B 配平：正样本多就保留优势最高的 B 个（消融：0.56 vs 随机 0.44），负样本多就随机取 B 个。
  • 正样本权重 ωiw = Aiw / mean(Aw)；负样本继承它被分配到的那个正目标的权重。

自洽性正样本分支为何不用另写

把 P̂ 对自身做式 (3)，由于对角代价 Ci,i = 0，恒等排列就是最优解——正样本匹配到自己。 代入时间感知场后分子分母正好约掉，塌回标准 rectified flow 动作：

vtarget = (xw − xtw) / (1−t) = (1−t)(xw − x0) / (1−t) = xw − x0 （式 8 · 退化）

② TDC：时间感知动态修正

有了目标之后，最naive 的选择是静态动作 xw* − x0。但负样本的中间状态 xtl 本来就不在通往 xw* 的直线上，积分一个常速度会累积正比于 t(xl − xw*) 的终点误差。 所以动作必须同时依赖当前状态和剩余时间：

vtargetcorrection(xtl, t, c) = (xw* − xtl) / (1 − t) （式 5 · 归航场）

问题是 1/(1−t) 在 t → 1 时发散。论文的处理很干净：给残差乘上时间权重 w(t) = (1−t)²， 这等价于让 (1−t)·vθ 去回归一个有界目标，奇异性正好被抵消：

(1−t)·vtargetcorrection = xw* − xtl = (xw* − x0) − t(xl − x0) （式 6 · 全区间光滑）
Lneg(θ) = 𝔼 ‖ ωw*·[ (1−t)vθ(xtl,t,c) − ((xw*−x0) − t(xl−x0)) ] ‖22 （式 7 · 负样本分支目标）

全套目标式 11

LDHO(θ) = η·Lneg + (1−η)·Lpos + β·Lreg
  • Lneg：负样本归航（式 7）
  • Lpos：正样本锚定，退化为带优势权重的标准 rectified flow（式 9）
  • Lreg = ‖vθ − vθref‖22：向冻结的参考策略做似然无关的速度正则（式 10）
  • 默认 η = 0.1、β = 1.0
η = 0 时（关掉负样本归航，只剩正样本分支）用户研究从 1.92 掉到 1.13，说明增益确实来自归航本身； 但 η 加到 0.5 也会掉（1.27）——归航强度要和正样本锚定配平。 β = 0（去掉参考策略正则）最惨，掉到 0.30，论文说此时策略会偏离预训练速度场并产生退化几何。

与 CFG 的关系式 12

同一个 CFG scale（默认 s = 3.0）被一致地用在 rollout 生成、策略更新和推理三处—— 保证策略优化发生在与探索/利用相同的动力学下。目标形式不变，只是把 vθ 换成引导后的 v̂θ。 消融显示 s = 3.0 优于 CFG-free（s = 1.0）与其他档位。

SECTION 04 · THEORY

端点行为：收敛到哪、收敛多快

论文给了两个命题（证明在附录），分别刻画收敛终点与训练动力学。这部分是 DHO 区别于「拍脑袋加个 loss」的地方。

PROPOSITION 1 · 收敛终点

原来生成 xl 的那个噪声，会被改道到 xw*

设 x0 在参考策略 vθref 下确定性映射到负样本 xl。 当策略收敛到最优归航场 v*(xt, t, c) = (xw* − xt)/(1−t) 时， 生成映射 Fθ 的终点被重定向，使得 Fθ*(x0) = xw*。

PROPOSITION 2 · 训练动力学

终点以几何速率闭合残差

在理想化的逐点收缩更新下，终端生成为 x1(τ) = (1 − (1−α)τ)·xw* + (1−α)τ·xl， 因而 limτ→∞ x1(τ) = xw*——以 (1−α)τ 的几何速率把 xl 与 xw* 之间的差距补上。

注意命题的条件性（论文自己也写明了）：MAM 是逐 mini-batch 重算的，配对关系可能变。 所以两个命题是在「配对固定」的区间内成立——每个区间各自提供一次朝当前目标的构造性修正； 只有当配对最终稳定下来时，上述递推才预测收敛到那个目标。Figure 4 给了定性示例：一只猫头鹰在训练中逐步变得「正朝向」。

SECTION 07 · ABLATIONS

把每个组件单独拆出来看

论文在 Stage I 上做了一系列消融，架构/流程/奖励模型/评测协议全部固定，只改被研究的因素。

⚠️ 读消融数字前必读：论文明确说明——每次用户研究都是在该比较组内部产生的相对排序， 所以这些分数只能在同表/同图内比较，不能跨表比。 例如 Table 4 的「动态 0.69」与 Table 3 的「w=(1−t)² 0.55」不属于同一组，数值高低没有可比性。下面两张图画的是同一表内的序列。

η = 0 即关掉负样本归航（只剩正样本分支）：1.13；η = 0.1 最优 1.92；继续加大反而掉（0.2 → 1.68，0.5 → 1.27）。

SECTION 08 · LIMITATIONS

论文自己写的，和本站想补的

LIMITATION 1 · 论文原文

奖励维度不够细

「设计一个能全面刻画参考图引导的 3D mesh 几何质量的奖励仍然困难，当前维度不足以准确反映更高精度的几何属性。」 计划：进一步拆分奖励维度 + 收集更多专业艺术家反馈。

LIMITATION 2 · 论文原文

DHO 只用在 lifting 阶段

Stage II 强条件于 Stage I 输出，rollout 多样性不足，因此保持冻结。计划：探索如何丰富 Stage II 的 rollout 多样性。

本站补充 1 · 指标

ULIP / Uni3D 基本不能分辨几何质量

Table 2 里最好的方法（0.150 / 0.360）与第 5 名（0.145 / 0.351）差距在第三位小数上，而用户研究差了一倍多。 这意味着整套结论的可信度几乎完全压在盲评流程上；若换一批评审或换一批参考图，排序是否稳定，论文没有给置信区间或显著性检验（只说了 3 seed 取均值）。

本站补充 2 · 复现性

奖励是闭源 API

用 Gemini 3.1 Pro 打分意味着奖励分布会随模型版本漂移，外部复现拿不到同一分布； 且 28 卡 rollout + API 调用的成本不低。论文没给出 API 调用量或单步 wall-clock，只给了推理侧的单样本耗时（Stage I 62 s + Stage II 81 s ≈ 143 s）。

本站补充 3 · 适用范围

没验证 2D

论文明确说：2D 视觉生成在预训练先验与奖励分布上都与 3D 不同，DHO 在 2D 上的表现留待后续探索。 换句话说，这篇不主张「DHO 也该取代 2D 上的 GRPO/NFT」，它的改进证据全部来自 3D mesh 生成。

本站补充 4 · 定位

与 Flow3D-OPD 的关系

Table 2 里排第二的是 Flow3D-OPD（7.04，Ning et al. 2026，同一批作者的前作）。 DHO 不是它的替代品而是正交方向：OPD 解决的是 3D 上 RL 的另一种适配问题，DHO 解决的是「负样本分支没有目标」。 两者叠加会怎样，论文没做。
