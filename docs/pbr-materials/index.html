PBR 材质生成专题梳理

素材来自本站 2026 年 6–8 月 3D 生成论文合集（183 篇）。按 PBR 生产管线 重新分层，逐层给出篇数、代表工作与技术取舍；并把所有工作对齐到 glTF 2.0 材质通道 做覆盖检查——空白项即机会点。

25 篇在范围内（+1 篇窗口外） 五层管线：采集 → 逆渲染 → 生成 → 结构分解 → 烘焙 glTF 9 个材质通道只覆盖 3 个 透明 / 折射参数化生成零覆盖

Section 1 · 结论先行

三条结论

如果只有五分钟，看这三张卡。

结论 01

只有 1 篇真正产出 glTF 完整 PBR 三件套

Luce（Apple，2608.23943，本站深度解读 →）把几何与 PBR 统一进体素化多模态高斯云，显式参数化 albedo / metallic-roughness / normal，可导出带切空间法线的贴图网格。其余 24 篇要么停在 albedo-shading 分解，要么把 BRDF 存在隐式 MLP 或调色板里，导不出 glTF 材质。

结论 02

透明 / 折射的参数化生成是彻底的空白

glTF 的 transmission / ior / volume / clearcoat / sheen / anisotropy 六个通道在 183 篇里零覆盖。唯一相关的是一篇 CAD 透明渲染综述（2608.28310）——它讲怎么画，不讲怎么估参数。

结论 03

6–7 月是逆渲染月，8 月是生成月

材质 / 光照分解的四篇主力（MaterialClusterGS、AEGIR、Editable PB Reflections、Intrinsic 3DGS）全部集中在 6 月。8 月出现两个新方向：生成即带材质（Luce）与 材质感知结构分解（PartMat、Gen2Physics）。

📌 一句话总结：学术界主流路径仍是「先重建几何与辐射场 → 再反推材质」，而不是「直接生成材质参数」。Luce 是这条主线上的第一个例外，也是唯一一个把 metallic-roughness 显式参数化的工作。

PBR 贴图要过五道关，论文密度极不均匀

从「透明物体怎么拍」到「贴图怎么落到资产上」，25 篇在这五层的分布是 3 / 10 / 3 / 2 / 3，外加 4 篇跨层工作。密度几乎全挤在逆渲染层。

PBR 材质生产管线五层与 glTF 通道覆盖（Ink3D 同时属于 L3 与 L5，此处归入 L3）

按管线分层去重后的分布：L2 逆渲染独占 40%，而 L3 生成式材质只有 12%。

Section 3 · 三条技术路线

逐基元 BRDF / 本征分解 / 生成式 latent

同一件事的三条路径，在可编辑性、可导出性、输入要求上差别很大。

代表MaterialClusterGS、InvSplat、SpotlessGSIntrinsic Decomp of 3DGS、Mesh2GS、LuceLuce、Home3D 1.0、Ink3D
材质表示每基元一个 BRDF（调色板原型 / MLP）albedo + shading 两个分量VAE 压进材质感知隐空间
光照模型环境光 SH 或显式面光源神经照明模块 / 分解出的 shading训练数据隐含，可重光照
输入多视图（位姿已知）多视图 / 网格 + 多视图单图
可重光照✅⚠️ 部分（需重估 shading）✅
能否导出贴图 / 网格❌ 大多停在 splat❌✅ Luce 可选出带切空间法线的贴图网格
材质编辑粒度逐基元 / 逐材质簇逐像素贴图级全局 latent 级
主要局限材质分解不唯一，逐基元噪声大非朗伯表面失效，粗糙度与金属度分不开需要大规模带材质标注数据
与 glTF 的接口BRDF 参数化的可辨识性问题对应 Disney BSDF 的 diffuse / specular 拆分最贴近 glTF 材质贴图产出
🎯 判断：路线 ① 适合做编辑（改一盏灯、改一处粗糙度）；路线 ③ 适合做生产（出资产）。路线 ② 是两者的中间态，也是目前论文最多但工程落地最尴尬的一档——分解出来的 albedo 没法直接当 baseColor 贴图用，因为它没剥掉金属度与粗糙度。
Section 4 · 标准化对齐

与 glTF PBR 参数化的覆盖检查

把 25 篇逐条对照 glTF 2.0 的材质通道。这是本页最有价值的一张表——空白处就是机会点。

glTF 通道覆盖情况说明
baseColor / albedo部分（约 8 篇）本征分解类工作都能出 albedo，但多数混着光照残留
metallicRoughness1 篇（Luce）只有 Luce 显式参数化 metallic-roughness
normal（切空间）1 篇（Luce，可选导出）其余都在 splat 域，没有法线贴图
occlusion / emissive0 篇—
KHR_materials_transmission0 篇透明材质最核心的通道，完全空白
KHR_materials_ior / _volume / _dispersion0 篇折射 / 衰减参数，完全空白
KHR_materials_clearcoat / _sheen0 篇涂层与织物，完全空白
KHR_materials_anisotropy0 篇各向异性（拉丝金属、头发），完全空白
KHR_materials_specular1 篇Editable PB Reflections 的 roughness 可编辑

Section 6 · 空白与机会

五个明确的空白位

从 183 篇的覆盖反推：哪些事没人做。

  1. 透明 / 折射的参数估计。合集内 0 篇。窗口外有 RefracGS（2603.21695），但它做的是新视角合成而非参数估计。把「从多视图估计 transmission + IOR + attenuation」做出来，是明确的空白位。
  2. metallic-roughness 的通用估计。只有 Luce 在生成式框架里做。逆渲染路线（MaterialClusterGS / AEGIR / Intrinsic 3DGS）全都停在 albedo 或 BRDF 原型，没有人把它落到 MR 两通道上。这是一条「把已有逆渲染工作接上 glTF 参数化」的低垂果实。
  3. 材质生成的评测标准缺失。合集里有 3D 生成的评测基准（P3D-Bench、3D-DefectBench、Judging to Improve、PIVOT），没有一个是针对材质 / PBR 的。材质分解的准确性目前靠重光照 PSNR 间接衡量，不区分「albedo 对但 roughness 错」和「两个都错」。
  4. 几何-材质的联合估计。绝大多数方法假设几何已给定。PartMat 与 Gen2Physics 是例外（用材质线索反推结构），但都还是粗粒度部件级，没到连续参数场。
  5. HDR 环境光的显式估计。AEGIR 处理局部面光源、SpotlessGS 用 SH 环境光，但都没显式输出可用的 HDR envmap。而 envmap 是 glTF 资产可重光照的前提。
🏭 工业界旁证：上述第 1、2 条空白不只是学术观察。腾讯 Hunyuan3D-Buffalo 1.0（2608.02711，87M 样本的统一 3D 多模态模型）在 §6 结论里把「端到端纹理编辑基本未被探索（largely unexplored），原因是缺乏合适的训练数据」列为 6 个未解问题之一，并进一步发问「几何与纹理表示能否联合建模」。也就是说：本专题统计出的材质/纹理工作稀缺，与一线团队自述的能力缺口是同一件事的两面 —— 需求侧明确存在，供给侧（数据 + 方法）都还是空的。
